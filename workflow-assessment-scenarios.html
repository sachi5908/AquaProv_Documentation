Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

Conditional Monte Carlo measurement propagationSensitivity to uncertainty and censoring assumptions

Conditional Monte Carlo measurement propagation

Monte Carlo propagation evaluates an output model repeatedly using draws from specified input distributions (Joint Committee for Guides in Metrology, 2008). For a positive detected concentration with supplied mean m and SD s, AquaProv uses a moment-matched lognormal marginal. Laboratory mode uses mapped SDs, scenario mode uses s = r·m for the selected relative SD r, and fixed mode uses a constant:

σ²log = ln[1 + (s/m)²]
μlog = ln(m) − σ²log/2
C* = exp(μlog + σlogZ),   Z ∼ Normal(0,1)

An optional shared log-error correlation ρ uses Zᵢ = √ρ Z₀ + √(1−ρ)εᵢ, with independent standard normal Z₀ and εᵢ. This is a specified log-error scenario, not an estimated concentration correlation. Zero with positive SD has no supported nonnegative moment-matched distribution; a missing laboratory SD is unassessed in laboratory mode.

Each draw is converted to equivalents and passed through the same SAR, sodium-percentage and graphical classification formulas as the deterministic diagrams. Reported intervals are the finite-draw 2.5th, 50th and 97.5th percentiles. Class and threshold probabilities are indicator frequencies:

P̂(event) = (1/B)∑b=1…B 1(event in draw b)
Monte Carlo SE = √[P̂(1−P̂)/B]

Wilson intervals describe binomial sampling precision for an estimated probability (Wilson, 1927). The exported 95% Wilson bounds and split-half difference describe simulation precision. They do not quantify whether the chosen SDs, distributions or correlation are scientifically correct. The irrigation interval view plots SAR and Na% intervals by sample; class probabilities are in the result tables. All conclusions are conditional on the chosen measurement and censoring model.

Implementation: aquaprovpy/assessment/uncertainty.py (draw_observation, draw_group, interval, probability, propagate).

Sensitivity to uncertainty and censoring assumptions

Sensitivity analysis examines how assumptions and input choices affect model conclusions (Pianosi et al., 2016). The comparison runs four alternatives: fixed detected values with censored cells excluded; relative-SD draws with censored cells excluded; relative-SD draws with C ∼ Uniform(0,L) for left-censored cells; and relative-SD draws with fixed C = L/2. Uniform censoring has mean L/2 and variance L²/12, whereas half-limit substitution has no within-limit variability.

Scenario probability range = [minsP̂s(C>H), maxsP̂s(C>H)]

The range plot shows up to 40 assessable assays and the bar chart summarizes conclusion labels across scenarios. “Stable below” requires all four scenarios to be assessable with every P ≤ 0.05; “stable above” requires every P ≥ 0.95. Other fully assessed cases are scenario-dependent or ambiguous, and incomplete cases have insufficient information. These are display rules, not regulatory thresholds. The span is not a probability-weighted average or a confidence interval: the software assigns no probabilities to the assumptions themselves. For a separate propagation run, a supplied lognormal model truncated below L is also supported, but it is not one of these four comparison cases.

Implementation: aquaprovpy/assessment/uncertainty.py (compare_scenarios, draw_observation), aquaprovpy/assessment/censoring.py.

1. Import this worked input#

Module: Assessment. Source: Sukinda_CGWB_Data_2024.xlsx / Selected_47_Samples. Prepared records: 47 (Sahoo et al., 2025).

All 47 source records. All 47 Sukinda rows; explicitly mapped source units. Positive concentrations use an assumed 5% relative-SD lognormal sensitivity scenario, 2,000 draws, seed 42, independent errors. These SDs are not laboratory estimates. WHO-2022-selected-chemicals-v1: NO3, F, total Cr and Ni only; not complete potability assessment. Fixed/exclude, relative-SD/exclude, uniform-below-limit and half-limit alternatives shown separately. No source reporting limits are invented; numeric-only analytes give identical censoring alternatives.

5. Export and preserve#

  1. Choose a descriptive file name and an output folder you control. Use separate names for alternatives.
  2. Select PNG/TIFF for raster output or SVG/PDF for vector-compatible output. Set DPI for raster output; verify final dimensions.

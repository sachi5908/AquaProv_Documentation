Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

From laboratory concentrations to chemical equivalents

A mass concentration gives the mass of an ion; an equivalent concentration also accounts for its electric charge. Let Cᵢ be concentration in mg/L, Mᵢ molar mass in g/mol (numerically also mg/mmol), and |zᵢ| the absolute ionic charge (Hem, 1985):

mᵢ = Cᵢ / Mᵢ (mmol/L)
eᵢ = |zᵢ| Cᵢ / Mᵢ (meq/L)

For an input already in meq/L, eᵢ is the supplied value. To recover mmol/L from meq/L, divide by |zᵢ|. These conversions are different for divalent ions such as Ca²⁺ and monovalent ions such as Na⁺.

Ion Mᵢ (g/mol) Absolute charge
Ca 40.0780 2
Mg 24.3050 2
Na 22.9898 1
K 39.0983 1
HCO₃ 61.0171 1
CO₃ 60.0092 2
Cl 35.4527 1
SO₄ 96.0636 2

Illustrative check: 40.078 mg/L Ca is 1 mmol/L and 2 meq/L; 22.9898 mg/L Na is 1 mmol/L and 1 meq/L. Equal molar concentrations do not mean equal charge contributions. Concentrations must be finite and nonnegative. A missing measurement does not become a measured zero; check the selected missing-data policy and any explicitly supplied values.

Implementation: aquaprovpy/ions.py (ions_WEIGHT, ions_CHARGE), aquaprovpy/_chemistry.py (major_ion_meq).

Normalize cations and anions separately

Using equivalents eᵢ, form the two charge totals and the six grouped fractions:

Tc = eCa + eMg + eNa + eK
Ta = eHCO₃ + eCO₃ + eCl + eSO₄
c = (eCa, eMg, eNa + eK) / Tc
a = (eHCO₃ + eCO₃, eSO₄, eCl) / Ta

Below, c₁, c₂, c₃ mean Ca, Mg and Na+K fractions, and a₁, a₂, a₃ mean HCO₃+CO₃, SO₄ and Cl fractions. Each triplet sums to 1; multiply by 100 for equivalent percentages. Both totals must be positive. AquaProv checks this before constructing normalized major-ion diagrams.

Normalization explains why these diagrams describe relative composition. Multiplying every concentration in a sample by ten leaves its position unchanged. Separate normalization also hides disagreement between cation and anion totals, so a plausible plotted position does not establish good charge balance (Piper, 1944).

Implementation: aquaprovpy/_chemistry.py and the normalization in each major-ion diagram's plot function.

Piper geometry: two triangles and a projected diamond

A ternary point is a weighted average of three vertices. With triangle height h = √3/2 and the diagram's horizontal gap o = 0.1, AquaProv uses:

xc = c₃ + c₂/2;   yc = h c₂
xa = 1 + 2o + a₃ + a₂/2;   ya = h a₂
xd = (xa + xc)/2 + (ya − yc)/(4h)
yd = (ya + yc)/2 + h(xa − xc)

The cation vertices represent Ca (left), Na+K (right) and Mg (top); the anion vertices represent HCO₃+CO₃ (left), Cl (right) and SO₄ (top). The diamond combines the two compositions by parallel projection. Its location is not an extra chemical measurement.

Illustrative check: c = (0.5, 0.25, 0.25) and a = (0.5, 0.25, 0.25) give (xc, yc) = (0.375, 0.2165), (xa, ya) = (1.575, 0.2165), and (xd, yd) ≈ (0.975, 1.2557). The fractions, rather than the physical page coordinates, carry the chemical meaning.

Piper's framework compares major-ion facies. Similar points can result from different reaction or mixing histories; use salinity, charge balance and independent hydrogeological evidence alongside the diagram (Güler et al., 2002; Piper, 1944).

Implementation: aquaprovpy/triangle_piper.py (plot).

Gaussian kernel density in Piper space

Large hydrochemical datasets motivate alternatives to overlapping points on conventional Piper diagrams (Moreno Merino et al., 2021; Russoniello & Lautz, 2020). Kernel density estimation summarizes the spatial density of observations (Silverman, 1986). AquaProv fits a separate two-dimensional Gaussian kernel density estimate to each triangle and the diamond. For points pᵢ and a location p in the same panel:

f̂(p) = [1 / (n · 2πb²)] ∑i=1…n exp(−‖p − pᵢ‖² / (2b²))
b = 0.05 in diagram-coordinate units

The code uses scikit-learn KernelDensity, evaluates a 500 × 500 support grid, and masks values outside the panel polygons. Filled levels follow the estimated density range. This is a display mask, not a boundary-corrected or renormalized density estimator, so kernels near a triangle edge still extend outside the domain mathematically.

All retained samples contribute equally; repeated observations can increase local density. Larger bandwidth would smooth more and smaller bandwidth would show finer structure; this plotting function fixes b at 0.05. The colours describe concentration of observations in composition space, not dissolved-solute concentration or geographic abundance. Compare panel patterns with their scales and the ordinary point plot.

Implementation: aquaprovpy/contour_piper.py (plot, _density_on_domain).

1. Import this worked input#

Module: Groundwater. Source: Sukinda_CGWB_Data_2024.xlsx / Selected_47_Samples. Prepared records: 47 (Sahoo et al., 2025).

All 47 Sukinda records; measured major ions in mg/L, converted by the AquaProv diagram engine. Reported zeros are preserved; missing ions are never created.

Download this route’s CSV ↓
  1. Open Groundwater and select Contour-filled Piper in the left Plot library. Use its search box to find the plot.
  2. Use Load data in the top toolbar, Ctrl + I, or Data → Dataset → Import CSV or Excel. Import the exact input linked on this page. Select the intended worksheet for a multi-sheet workbook and check the row count and headers in the Data inspector.
  3. Turn Auto update off while entering the worked choices. In the right inspector, open the named tab and click a section heading to expand it; scroll down for the lower controls.
  4. Open Settings → Diagram & method → Concentration unit and match mg/L or meq/L to the source. The selector declares input units; it does not rewrite the imported table. Check the required ions described in the method section.
  5. For plots with configurable sample symbols, open Settings → Sample appearance. Select Group samples by, a numeric Color by numeric column or a single colour, then set Marker, Size and Opacity. Scientific diagram colours can be fixed by the method.
  6. Click Generate figure or Generate map, or press F5. Open Export → Results & methods to review exclusions, diagnostics, numerical tables and methods before interpreting or exporting the figure.

4. Refine the figure style

  1. In the right inspector, open Settings → Plot settings. Use Show plot title and Manual plot title (optional); leave the title blank for the automatic title. Set title size, weight, style and position here.
  2. Open Style → Publication figure → Typography. Choose the font family and annotation, axis-label, tick and legend sizes. The top toolbar also provides quick typography controls.
  3. In Style → Publication figure, open Labels & ticks to edit axis labels, visibility, limits, ticks and tick formats. Enter the colourbar title in Color scale label (blank = original). Keep quantity and units in labels; blank labels and limits retain the original labels and automatic bounds.
  4. In the same Publication figure panel, open Canvas & grid to set backgrounds, axis borders, grid visibility and layout padding. For geographic frames, use the map-specific Settings → Coordinates and grid controls when available.
  5. Open Style → Publication figure → Legend & color scale. Set Legend position (also draggable), columns, frame and individual Legend items for this plot. Choose Colour scale, Show colourbar and colourbar text sizes for numeric colours. Sample plots need a numeric colour column for a continuous scale; categorical groups use their group colours. Normalize colour scale to 0–1 changes display labels while retaining measurements and scientific classifications.
  6. Open Style → Publication figure → Dimensions & export. Choose Figure sizing → Custom, then set Width (inches) and Height (inches). Review Transparent background and Crop to content; cropping can change exported dimensions.
  7. Click Apply style and inspect the figure at its intended final size. Save preset and Load preset reuse presentation settings. Method, variable, grouping, sample-symbol and interpolation changes require Generate when Auto update is off.

5. Export and preserve

  1. Finish the calculation with Generate figure or Generate map (or F5). Read the warnings, then apply the final style.
  2. Open Export → Figure export. Enter File name, use Save to → Browse to choose your output folder, then select File format and Image resolution (DPI). Use distinct names for alternative results.
  3. Click the format-specific button, such as Export PNG, Export SVG or Export PDF. Open the saved file and check labels, legends, dimensions and the current view. Raster pixel dimensions depend on figure size and DPI.
  4. Open Export → Results & methods. Select a result table to inspect it. Choose Report format: CSV + JSON, Excel (.xlsx), Word (.docx) or PDF (.pdf), then click its export button. Available tables depend on the plot; some geochemical diagrams do not expose a table for every graphical element.
  5. Press Ctrl + S to save the .aquaprov project, including its data and per-plot settings. Keep the original measurements, exported results and final figure together.

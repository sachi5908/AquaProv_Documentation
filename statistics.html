Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

The statistical analysis matrix

Let X contain n retained samples (rows) and p explicitly selected measurements (columns). IDs and coordinate columns should only enter if they are the scientific variables being studied. The default rejects missing measurements and constant columns; explicit drop policies use complete rows across the selected variables and record exclusions. There is no automatic imputation, logarithm, outlier removal or conversion from the ion-unit selector.

For standardized analyses, AquaProv subtracts each variable's mean and divides by its sample standard deviation (Jolliffe & Cadima, 2016):

x̄ⱼ = (1/n)∑ᵢ xᵢⱼ
sⱼ = √[∑ᵢ(xᵢⱼ − x̄ⱼ)²/(n − 1)]
zᵢⱼ = (xᵢⱼ − x̄ⱼ)/sⱼ

Center-only PCA/HCA uses xᵢⱼ − x̄ⱼ without division. The standardized sample heatmap and standardized boxplots always use sample z-scores; the scatter matrix displays original units. For the illustrative values 1, 2, 3, the mean is 2, sample SD is 1 and z-scores are −1, 0, 1. Changing the retained rows changes these preprocessing quantities.

Implementation: aquaprovpy/_publication.py (numeric_frame, standardize), aquaprovpy/multivariate.py.

Standardized sample heatmap

Colour-coded matrices support visual comparison of multivariate patterns (Cleveland, 1993). Cell (i, j) is zᵢⱼ = (xᵢⱼ − x̄ⱼ)/sⱼ, with a symmetric diverging scale about zero. A value of +2 is two sample SDs above the retained mean of that variable; −1 is one SD below it. This compares patterns across variables with different units. It is not a concentration map, correlation matrix or health classification. Samples retain their analysis order; no clustering/reordering is implied by adjacent rows. If labels are thinned for readability, all sample rows remain plotted and exported.

Implementation: aquaprovpy/multivariate.py (plot, view='heatmap').

Pairwise scatter panels and marginal histograms

Off-diagonal panel (j, k) plots retained pairs (xᵢₖ, xᵢⱼ) in the original measurement units. Diagonal panels show each variable's histogram. Shared complete-case filtering is performed before any panel, so the same samples appear across the matrix. Although a standardized table is also exported, it is not the plotted coordinate table for this view. The matrix adds no regression line, correlation test, log transform or outlier removal. Curvature, clusters and extreme observations can explain why one summary correlation is inadequate (Cleveland, 1993).

Implementation: aquaprovpy/multivariate.py (plot, view='scatter_matrix'), pandas scatter_matrix with histogram diagonal.

Quartiles, whiskers and individual extremes

For a set of finite plotted values v, let Q₁, Q₂ and Q₃ be the 25th, 50th and 75th percentiles. AquaProv's NumPy/Matplotlib path uses linear quantiles. If sorted values are v₍₀₎…v₍ₙ₋₁₎, a quantile q lies at index (n−1)q and linearly interpolates neighbouring values (Hyndman & Fan, 1996).

IQR = Q₃ − Q₁
Lower fence = Q₁ − 1.5 IQR;   upper fence = Q₃ + 1.5 IQR

The box spans Q₁ to Q₃ with a median line. Whiskers reach the most extreme observations within the fences, not necessarily the fence coordinates. Values beyond the whiskers remain observations; the plot does not remove them. For values 1, 2, 3, 4, 9, Q₁ = 2, median = 3, Q₃ = 4, and the upper fence is 7, so 9 is beyond the whisker. This descriptive range is not a confidence interval (Tukey, 1977).

Which values enter the standardized boxplots

Each variable's box uses its sample z-scores, not its raw concentrations. Zero is the variable mean; the median need not be zero for an asymmetric sample. Standardization gives each variable sample SD 1 but does not make its distribution normal. Different-looking boxes therefore reveal shape and relative extremes after differences in units and spread are removed.

Implementation: aquaprovpy/multivariate.py (plot, view='boxplot').

Measurements against source-row positions

For source row r = 1,…,n and series j = 0,…,m−1, the vertical coordinate is the supplied measurement vᵣⱼ. A chosen horizontal separation δ distinguishes overlapping series:

xᵣⱼ = r + [j − (m−1)/2]δ;   yᵣⱼ = vᵣⱼ

For two series and δ = 0.36, row 10 appears at X = 9.82 and 10.18. Both positions still refer to source row 10. The offset changes display positions only. No dates, fitted trend or interpolated measurements are created. Compare quantities with compatible units, or label their differing units clearly; the plot does not convert them.

Missing values are omitted separately in each series while preserving the original row positions. Reported zeros remain exactly zero and can use open markers. Non-numeric and infinite measurements must be resolved before plotting. An optional horizontal threshold is entered in measurement units and does not classify a water sample or establish compliance by itself.

The worked input retains all 47 Sukinda source rows and plots NO3 and F in mg/L. The exported series_observations table records row, sample, variable, value, reported-zero status and whether the value was plotted. Source ordering alone does not establish a time sequence or spatial gradient.

Implementation: aquaprovpy/measurement_series.py (plot).

A common data contract#

Select numeric measurement variables explicitly. Standard statistical methods do not convert units or infer a detection-limit model. The GUI offers complete-case exclusion and reports the cohort; the Python engine defaults to stopping on missing values. Non-numeric qualifiers such as <0.01 require a defensible treatment before ordinary statistical analysis.

Constant variables stop analysis by default or can be explicitly dropped and reported. There is no automatic log transform, outlier deletion, or replacement of missing values with zero.

An example variable set#

The Sukinda worked data are attributed to their associated source publication (Sahoo et al., 2025). The worked Sukinda examples use pH, Ca, Mg, Na, K, HCO3, Cl, SO4 and all 47 records. CO3 is constant zero and is omitted; IDs, coordinates, redundant totals, and trace-metal columns are not included in this particular example. This is a documented tutorial choice, not a universal recommended model.

Before making inference, establish whether the records are independent observations. For repeated wells, use well-level analysis or design a method appropriate to the sampling structure.

Compare measurements in source-row order

Choose Plot library → Measured series · source rows. Check the required measurements in Settings → Analysis settings → Measurement variables (checked = included). Under Settings → Time series & uncertainty, set series order, colours, markers, legend names and horizontal separation. Enable Draw reported zeros as open markers to distinguish zeros. This plot uses source-row order and needs no date column. The worked NO3 and F guide retains all 47 Sukinda row positions and omits missing values separately for each series.

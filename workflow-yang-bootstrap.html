Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

Independent-row percentile bootstrap

Independent-row percentile bootstrap

For n retained measurements, AquaProv draws B replacement samples of size n. It computes the selected mean or median θ*b from each sample. The observed estimate θ̂ is calculated on the original retained data (Efron & Tibshirani, 1993):

Confidence interval = [Qα/2(θ*), Q1−α/2(θ*)]
α = 1 − confidence/100
Bootstrap SE = sample SD of θ*₁,…,θ*B

The histogram contains the B statistic estimates, not the original measurements. At 95% confidence the interval uses the 2.5th and 97.5th percentiles (NumPy linear quantiles). Defaults are 2,000 resamples and seed 42; the accepted range is 200–20,000 with at least three complete observations. The seed makes a given configuration reproducible, not scientifically certain.

The interval concerns sampling variation of a mean or median under independent, representative rows. It is neither a prediction interval for a new measurement nor propagation of laboratory SD. Repeated observations at wells require an appropriate grouped design such as the well-bootstrap assessment. Constant observations produce a degenerate interval; small samples may give poor coverage.

Implementation: aquaprovpy/exploration.py (bootstrap, plot).

1. Import this worked input#

Module: Statistics. Source: data_Yang_et_al_2020.xlsx / Data. Prepared records: 29 (Yang et al., 2020).

Dry-season 2005 campaign: 29 distinct wells. Mean Ca for 29 wells in the dry 2005 campaign; 5,000 independent-row percentile bootstrap resamples, seed 42, 95% interval. Ca assumed mg/L. This sampling illustration assumes independent representative wells; spatial dependence is not resolved.

Download this route’s CSV ↓
  1. Open Statistics and choose Uncertainty · bootstrap interval in the left Plot library.
  2. Choose Data → Import CSV or Excel and import the prepared CSV above. Confirm 29 rows. This CSV is a declared working copy; the original dataset is retained in Datasets.
  3. Keep Auto update off while entering settings. Check the Data panel below, including units, coordinates or measurement mappings when present.

4. Refine the Style panel#

Open Typography, Labels & ticks, Canvas & grid, Legend & color scale, or Dimensions & export. Use the illustrated Style reference for all five sections. Apply presentation changes, then inspect labels, legend and final physical dimensions. Sample grouping/symbol changes belong to Settings and require Generate.

5. Export and preserve#

  1. Choose a descriptive file name and an output folder you control. Use separate names for alternatives.
  2. Select PNG/TIFF for raster output or SVG/PDF for vector-compatible output. Set DPI for raster output; verify final dimensions.
  3. Click the named Export button. Save numerical Results & methods separately when available.
  4. Save the .aquaprov project.

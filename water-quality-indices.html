Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

Calculate the index before drawing the plot

Weighted indices combine parameter ratings after specifying standards and relative contributions (Ramakrishnaiah et al., 2009). For each sample and selected parameter i, first convert concentration Cᵢ into the canonical unit and named chemical basis of its standard. Let Iᵢ be the ideal, Sᵢ the rating standard, and Wᵢ the normalized weight. The arithmetic index is:

Index = ∑ᵢWᵢqᵢ;   ∑ᵢWᵢ = 1
Ratio rating: qᵢ = 100Cᵢ/Sᵢ
Ideal rating: qᵢ = 100(Cᵢ − Iᵢ)/(Sᵢ − Iᵢ)

For a two-sided rating with Lᵢ < Iᵢ < Uᵢ, use qᵢ = 100(Cᵢ−Iᵢ)/(Uᵢ−Iᵢ) above the ideal, and qᵢ = 100(Iᵢ−Cᵢ)/(Iᵢ−Lᵢ) below it. This differs from the signed ideal formula, which may produce negative ratings. An ideal of zero makes the upper-standard ideal rating equal to the ratio rating. Individual ratings and contributions Wᵢqᵢ are exported.

Selected method Normalized weights and meaning
Weighted arithmetic WQI (inverse-standard weights) Wᵢ = (1/Sᵢ)/∑ⱼ(1/Sⱼ), using canonical standard units
Relative-weight groundwater WQI Wᵢ = wᵢ/∑ⱼwⱼ from the chosen positive importance weights
Weighted DWQI The same weighted-sum form with independently chosen DWQI parameters, ratings and importance weights
Custom weighted DWQI The explicitly configured weights, ratings, limits and classification define the calculation

The original NSF water-quality index combined ratings for selected water-quality characteristics (Brown et al., 1970). The weighted arithmetic option implements this inverse-standard convention; it does not reproduce the original NSF nine-parameter rating curves. Inverse-standard weights depend on the declared canonical units, so input and standard unit conversion must precede weighting. DWQI has no single universal formula. A method name alone is insufficient to reproduce a result.

Illustrative calculation: with ratio ratings C = (10, 0.75) mg/L and S = (50, 1.5) mg/L, q = (20, 50). Inverse-standard weights are (3/103, 100/103), giving WQI ≈ 49.126. Equal importance weights instead give 35. This is a two-parameter arithmetic illustration, not a validated drinking-water assessment or CCME dataset.

An arithmetic score requires every selected measurement in the row. If any are missing, the score remains unassessed; weights are not renormalized to the available subset. A favourable composite can coexist with an individual exceedance. Review selected hazards, standards edition, per-parameter compliance and missing counts.

Implementation: aquaprovpy/water_quality/common.py (unit_factor, ratings, aggregate_arithmetic), aquaprovpy/water_quality/wqi.py, aquaprovpy/water_quality/dwqi.py.

Alternative WQI: CCME scope, frequency and amplitude

The CCME index combines scope, frequency and amplitude of guideline nonattainment; the 2017 manual recommends more than the original four-parameter minimum when suitable monitoring data are available (Canadian Council of Ministers of the Environment, 2001, 2017). If CCME is selected, AquaProv calculates one WQI per site/period from repeated occasions rather than one arithmetic score per row. It requires at least four selected variables and at least four measured occasions per variable in each site/period. Duplicate site/period/occasion records must be resolved explicitly.

F₁ = 100 × variables failing at least once / selected variables
F₂ = 100 × failed tests / measured tests
Upper-limit excursion = C/U − 1 when C > U
Lower-limit excursion = L/C − 1 when C < L
nse = ∑ excursions / measured tests
F₃ = 100 nse/(1+nse)
CCME WQI = 100 − √[(F₁² + F₂² + F₃²)/3]

Passing tests contribute zero excursion. Missing tests contribute neither passes nor failures. A zero failing a positive minimum has infinite excursion and the limiting F₃ = 100. An exceeded zero upper limit cannot be ratio-normalized and is rejected. Groups with insufficient tests remain unassessed. Higher CCME values indicate better attainment, the opposite numerical direction from arithmetic WQI/DWQI. CCME does not use arithmetic importance weights or ideals.

The supplied WQI/DWQI worked figures use arithmetic methods; this alternative explains how the calculation changes when the method selector changes. CCME categories assess attainment of selected objectives, not complete drinking-water safety.

Implementation: aquaprovpy/water_quality/wqi.py (ccme_wqi).

Turn index values into classes

Classification is applied to the full-precision score after calculation. Default arithmetic WQI cuts are 25, 50, 75 and 100; default relative-weight WQI/DWQI cuts are 50, 100, 200 and 300. Both use the labels Excellent, Good, Poor, Very Poor and Unsuitable in that order, and both include an exact cut in the lower-valued class. Thus arithmetic WQI = 25 is Excellent, while 25.01 is Good.

CCME uses cuts 45, 65, 80 and 95 with labels Poor, Marginal, Fair, Good and Excellent. Exact cuts enter the next higher class; 95 is Excellent. Custom schemes can change these thresholds, colours and inclusion rules. Nonfinite scores are Unassessed. Always interpret the exported classification scheme rather than assuming colours imply universal thresholds.

Implementation: aquaprovpy/water_quality/common.py (SCHEMES, classify, classification_table).

Parameter compliance uses its own measured denominator

For each parameter i, a finite measurement meets the selected limits when C ≥ L (if a lower limit exists) and C ≤ U (if an upper limit exists). Equality at either limit is compliant. Let nᵢ count measured tests and fᵢ count failures:

Outside limits (%) = 100fᵢ/nᵢ
Meets limits (%) = 100(nᵢ − fᵢ)/nᵢ

The horizontal stacked bars sum to 100% for each assessed parameter. Missing counts are separate; nᵢ can differ between parameters and can exceed the number of complete composite indices. If nᵢ = 0, the percentage is undefined. For 45 measured tests with 9 failures, the bars are 20% outside and 80% meeting limits, regardless of other parameters' missing records. This view tests individual concentrations, not whether a WQI/DWQI score passes a class threshold.

Implementation: aquaprovpy/water_quality/common.py (prepare), aquaprovpy/water_quality/plots.py (view='compliance').

Arithmetic means of index records within site and season

For site s, season t and nst available scores, each bar is:

Īst = (1/nst)∑r in site s, season tIᵣ

AquaProv calculates each record's index before averaging. The exported seasonal_site_statistics contains means, counts and sample SDs; bars themselves do not show an inferred confidence interval. A missing site–season combination is a gap, not zero. Seasonal summary tables also give mean, median and sample SD across available records. These descriptive comparisons do not account for unequal repeats or establish a paired seasonal effect.

Implementation: aquaprovpy/water_quality/plots.py (view='seasonal_bars').

Seasonal boxes pool available scores

Each selected season contributes all its finite sample/site-period scores to one box. These are raw index values, not standardized values and not first averaged to equal-weight site means. Whiskers and fliers follow the quartile rule above; summary tables give each season's count, mean, median and sample SD. A well sampled repeatedly can contribute repeatedly. Different well coverage or sample counts can shift a box even without a within-well seasonal change.

Implementation: aquaprovpy/water_quality/plots.py (view='seasonal_box').

WQI and DWQI side-by-side maps

WQI and DWQI are calculated independently with their selected methods, weights and classification schemes, then mapped independently. Their numerical colour scales remain separate. A value of 50 need not mean the same class, parameter contribution or attainment in both panels. Spatial differences can arise from weighting choices alone. Compare exported per-parameter contributions and schemes before interpreting them as a physical change in water quality; there is no subtraction, averaging or conversion between the two indices in this view.

Implementation: aquaprovpy/water_quality/engine.py (calculate), aquaprovpy/water_quality/plots.py (view='comparison').

Data & assumptions for these figures#

The selected WHO chemical guidelines use the 2026 edition (World Health Organization, 2026). The Sukinda worked data are attributed to their associated source publication (Sahoo et al., 2025). Sukinda: all 47 source rows; NO3 and F in mg/L, and total Cr, Ni and Mn converted from aqueous ppb to mg/L (divide by 1,000). Reported Mn is treated as compatible with the WHO total-manganese entry for this example; verify the laboratory fraction for a study. The WHO 2026 profile supplies objectives of 50, 1.5, 0.05, 0.07 and 0.08 mg/L, respectively. WQI uses inverse-standard weights; DWQI uses equal importance weights (1 each). Missing nitrate at sample 30 and fluoride at sample 31 leave 45 complete composite indices. Parameter compliance still uses each parameter’s measured denominator.

The Liu worked data are attributed to their associated source publication (Liu et al., 2021). Liu: 38 measurements from 19 wells in April and September 2015. Only NO3 and F are selected, with assumed mg/L units. These campaign examples explain the seasonal controls; two parameters do not establish drinking-water quality. Calendar months are retained without inventing a monsoon label. The provided data do not satisfy a four-variable CCME demonstration with this parameter selection.

Maps use WGS84 longitude/latitude, local metric distances, IDW power 2, a 60 × 60 grid and the sample-hull mask. They use a plain background and need no map service. Numerical interpolation should be validated before study-level interpretation.

Open WQI & DWQI from the home page or module menu. The plot library contains twelve WQI views, twelve DWQI views and a side-by-side comparison. Each index has its own method, selected parameters, weights, ideal values, standard selection and classification scheme. These settings are shared across its views and saved in the project; figure appearance is saved per plot.

Workflow#

  1. Import the measurement table. Use one row per sampling event and a stable site identifier for repeat visits. Keep a season column (for example Pre-monsoon and Post-monsoon) and a sampling-occasion column for CCME.
  2. Choose a plot, then select Methodology, Standards database and Limit category under Settings. WHO guideline values and BIS acceptable/permissible limits are separate selections.
  3. Open Review parameters, weights, units and limits. Only exact-name matches to available limits are suggested. Review species, input units, selected parameters and provenance. A column named NO3 means nitrate as NO3, not nitrate expressed as nitrogen; convert species bases before importing. Defaults are suggestions, not confirmation of a laboratory unit.
  4. For spatial plots, choose X/Y, source CRS, and distance coordinates. Choose a single season if repeated visits have the same coordinates. Interpolation rejects duplicate locations rather than silently averaging visits. Sampling-point plots can display multiple records; hover reveals actual values.
  5. Choose IDW or ordinary kriging, grid resolution, variogram settings, boundary coverage, colours and labels. Kriging range is in analysis distance units, while partial sill and nugget are in squared index units. Parameters are user-supplied; validate the variogram using AquaProv's spatial assessment tools.
  6. Generate. Use the normal figure tools to pan, zoom, inspect samples, or rotate the 3D surface. The View menu provides exact camera angles. Export PNG, SVG or PDF using the existing Figure export controls. Results & methods exports contain the method, standard profile, per-parameter edition and amendment provenance, classifications, source-row audit, compliance counts and interpolation grids.

Implemented methods#

For parameter i, C_i is concentration converted into the standard's units, S_i is the selected standard and I_i is the ideal value. Ratings are never capped at 100.

Method Computation Default classification
Weighted arithmetic WQI, inverse-standard weights W_i = (1/S_i) / Σ(1/S_i); WQI = Σ W_i q_i. Default q_i = 100(C_i−I_i)/(S_i−I_i). Excellent, Good, Poor, Very Poor, Unsuitable; cuts 25, 50, 75, 100; lower is better.
Groundwater WQI, Ramakrishnaiah formulation W_i = w_i / Σw_i; q_i = 100 C_i/S_i; WQI = Σ W_i q_i. Same five labels; cuts 50, 100, 200, 300; lower is better.
Weighted DWQI, Ramakrishnaiah approach Independently configured drinking-water parameters and limits; DWQI = Σ(w_i/Σw_i) q_i. Same five labels; cuts 50, 100, 200, 300; lower is better.
Custom weighted DWQI Same auditable weighted sum with user-defined weights, ratings, ideals, limits and classes. Editable five-class scheme.
CCME WQI 1.0 100 − sqrt((F1²+F2²+F3²)/3) for each site/assessment period. Poor, Marginal, Fair, Good, Excellent; cuts 45, 65, 80, 95; higher is better.

The arithmetic schemes include each boundary in the lower-score interval (for example, WQI 25 is Excellent and 50 is Good). CCME includes each boundary in the higher-score interval (95 is Excellent). The boundary rule, labels, colours, cuts and scheme name are editable and exported. “Ramakrishnaiah-style” describes the adopted five-class ranges with this explicit boundary convention.

Attribution: Brown et al. (1970), A Water Quality Index—Do We Dare?, is the requested historical reference. Its original NSF index uses parameter rating curves. AquaProv's named Brown-family option implements the commonly used inverse-standard weighted-arithmetic convention, not those NSF curves. This distinction is also included in calculation reports. Ramakrishnaiah et al. (2009), Assessment of Water Quality Index for the Groundwater in Tumkur Taluk, Karnataka State, India, supplies the relative-weight formulation. AquaProv uses the current configured parameter set and standards, not the paper's historical dataset. Importance weights initially equal 1 and must be configured for the study; they are not claimed to reproduce the paper's weight schedule.

The parameter editor supports three explicit rating rules:

  • ratio: 100 C/S.
  • ideal: signed 100(C−I)/(S−I), using an upper objective or a lower objective when no upper bound is present.
  • two_sided: 100(C−I)/(upper−I) above the ideal and 100(I−C)/(I−lower) below it. This is an explicit modification for a range parameter, not silently substituted into a published method.

The signed ideal rule can give negative pH subindices below the ideal. Those values remain visible in the audit and produce a report note. Two-sided compliance always checks both limits independently of the selected rating rule. A satisfactory composite index can coexist with individual exceedances; the index is not a certificate of drinking-water safety.

CCME repeated-test assessment#

CCME is calculated once per site and assessment period, not once per individual chemical sample. Choose the site, sampling-occasion and optional season/period columns. Distinct occasions are required. Duplicate site/period/occasion records must be resolved explicitly. AquaProv conservatively requires at least four variables with at least four measured tests each in every group; insufficient groups remain Unassessed. The CCME user manual explains the original 2001 minimum and the advantages of more extensive monitoring.

  • F1: 100 × variables failing at least once / selected variables.
  • F2: 100 × failed tests / measured tests.
  • Upper-objective excursion: C/S−1; lower-objective excursion: S/C−1.
  • nse: sum of excursions / measured tests, including passing tests in the denominator.
  • F3: 100 nse/(nse+1).

A zero measurement failing a positive minimum has infinite excursion, so its amplitude takes the limiting value 100. A failed zero-tolerance upper objective cannot be ratio-normalized and is rejected. Arithmetic weights and ideal values do not enter CCME. Spatial CCME plots require a stable coordinate for all visits belonging to a site/period. Seasonal CCME maps require enough repeat observations in each season.

CCME categories describe attainment of the chosen objectives, often for aquatic ecosystem assessment. They are never relabelled as drinking-water safety classifications. Select objectives appropriate to the intended use.

Standards and provenance#

The bundled WHO database transcribes numeric chemical guideline entries from Annex 3, Table A3.3, printed pages 551–554 of the WHO 2026 fourth edition incorporating the first, second and third addenda, verified against its official PDF. Provisional values and special species/exposure conditions retain notes. Long-term cyanotoxin guidelines are used where the table also supplies short-term values. The database is a chemical-index resource, not a full assessment of microbiological, radiological, operational or mixture hazards.

WHO does not establish health-based guidelines for several common index variables, including pH, TDS and hardness. These entries have no numeric objective and are not automatically selected. BIS values are never used to fill them. If both WHO nitrate and nitrite are selected, their combined guideline-ratio test is exported separately; it is not counted again in index weights. Other mixture rules, such as combined trihalomethanes, require separate assessment.

The BIS IS 10500:2012 profile identifies the second revision, amendments 1–4 (2015, 2018, 2020 and 2021) and the 2023 review requested for this project. The consolidated amendment text could not be retrieved during implementation. Both acceptable and permissible entries therefore remain unverified and unset. No updated limits have been estimated, and the original PDF is not treated as incorporating all amendments. Import reviewed limits from the BIS standards record and original standard before calculating against this profile.

Every limit records edition, amendment, publication year, source, page, verification status and notes. Parameter-editor changes become unverified unless the user explicitly records having verified the edits against the cited official documents. Reports disclose unverified parameters.

Importing reviewed updates

Use Export selected standards / update template to save the complete structured profile, transcribe reviewed changes from official documents, and use Import reviewed standards to load it. Imported updates to a bundled profile receive a separate identifier; the bundled snapshot is preserved. Imports accept CSV; there is no automatic PDF-to-limit extraction or unreviewed OCR.

CSV columns are:

standard_id,standard_name,parameter,unit,limit_kind,lower,upper,edition,amendment,publication_year,source,page,verification,notes

Use one row per parameter and limit kind (acceptable, permissible or guideline), with blank bounds for absent limits. A CSV describes one profile. Keep acceptable and permissible values in separate rows. Use a new profile ID for each revision. Numeric limits, ordered ranges, unit consistency and provenance are validated on import. verification is verified or unverified; it records the curator's review, not an automated certification.

Missing data, maps and comparisons#

Arithmetic indices require every selected parameter for that sample. Missing values produce Unassessed indices; weights are never silently renormalized. Non-numeric values, censoring qualifiers, infinities and physically invalid negative concentrations must be resolved before calculation. Compliance percentages use the measured denominator for each parameter, with assessed and missing counts shown; missing results are not counted as passing.

IDW and ordinary kriging operate on continuous calculated indices. Classification zones are assigned to the predicted grid afterward. The default mask is the sampled convex hull; an imported/drawn study boundary can clip it or explicitly enable extrapolation. Extrapolated cells and kriging prediction variance are exported. A boundary is not a groundwater-flow barrier. Kriging may predict outside the observed index range; AquaProv reports the values without hidden clipping.

Seasonal maps use a common coordinate origin, equal map extents and common colour limits. Their sampled hulls may differ. Grouped seasonal bars show a mean per site/season, with counts and SDs exported; missing combinations are gaps. Box plots and violins use available index records and report sample counts. These are descriptive comparisons, not paired significance tests. Constant or singleton data are shown as observations in the violin view because a density cannot be estimated.

WQI/DWQI comparison maps use separate numerical scales and retain both calculation reports. In particular, CCME's higher-is-better score cannot be compared numerically as if it had the same meaning as an arithmetic DWQI.

Compare WQI and DWQI by source row

In the Plot library, choose WQI · Sampling points and values, review its profile in Settings → Index calculation, then choose DWQI · Sampling points and values and review that profile. Select WQI versus DWQI scatter after both reviews. WQI is on X and DWQI on Y. Open Settings → Reference lines and notes for the identity line and Settings → Point colours, zeros & thresholds for optional source-column highlighting. The worked guide provides 45 assessable pairs from the 47-row Sukinda input.

Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

Calculate the index before drawing the plot

Weighted indices combine parameter ratings after specifying standards and relative contributions (Ramakrishnaiah et al., 2009). For each sample and selected parameter i, first convert concentration Cᵢ into the canonical unit and named chemical basis of its standard. Let Iᵢ be the ideal, Sᵢ the rating standard, and Wᵢ the normalized weight. The arithmetic index is:

Index = ∑ᵢWᵢqᵢ;   ∑ᵢWᵢ = 1
Ratio rating: qᵢ = 100Cᵢ/Sᵢ
Ideal rating: qᵢ = 100(Cᵢ − Iᵢ)/(Sᵢ − Iᵢ)

For a two-sided rating with Lᵢ < Iᵢ < Uᵢ, use qᵢ = 100(Cᵢ−Iᵢ)/(Uᵢ−Iᵢ) above the ideal, and qᵢ = 100(Iᵢ−Cᵢ)/(Iᵢ−Lᵢ) below it. This differs from the signed ideal formula, which may produce negative ratings. An ideal of zero makes the upper-standard ideal rating equal to the ratio rating. Individual ratings and contributions Wᵢqᵢ are exported.

Selected method Normalized weights and meaning
Weighted arithmetic WQI (inverse-standard weights) Wᵢ = (1/Sᵢ)/∑ⱼ(1/Sⱼ), using canonical standard units
Relative-weight groundwater WQI Wᵢ = wᵢ/∑ⱼwⱼ from the chosen positive importance weights
Weighted DWQI The same weighted-sum form with independently chosen DWQI parameters, ratings and importance weights
Custom weighted DWQI The explicitly configured weights, ratings, limits and classification define the calculation

The original NSF water-quality index combined ratings for selected water-quality characteristics (Brown et al., 1970). The weighted arithmetic option implements this inverse-standard convention; it does not reproduce the original NSF nine-parameter rating curves. Inverse-standard weights depend on the declared canonical units, so input and standard unit conversion must precede weighting. DWQI has no single universal formula. A method name alone is insufficient to reproduce a result.

Illustrative calculation: with ratio ratings C = (10, 0.75) mg/L and S = (50, 1.5) mg/L, q = (20, 50). Inverse-standard weights are (3/103, 100/103), giving WQI ≈ 49.126. Equal importance weights instead give 35. This is a two-parameter arithmetic illustration, not a validated drinking-water assessment or CCME dataset.

An arithmetic score requires every selected measurement in the row. If any are missing, the score remains unassessed; weights are not renormalized to the available subset. A favourable composite can coexist with an individual exceedance. Review selected hazards, standards edition, per-parameter compliance and missing counts.

Implementation: aquaprovpy/water_quality/common.py (unit_factor, ratings, aggregate_arithmetic), aquaprovpy/water_quality/wqi.py, aquaprovpy/water_quality/dwqi.py.

Alternative WQI: CCME scope, frequency and amplitude

The CCME index combines scope, frequency and amplitude of guideline nonattainment; the 2017 manual recommends more than the original four-parameter minimum when suitable monitoring data are available (Canadian Council of Ministers of the Environment, 2001, 2017). If CCME is selected, AquaProv calculates one WQI per site/period from repeated occasions rather than one arithmetic score per row. It requires at least four selected variables and at least four measured occasions per variable in each site/period. Duplicate site/period/occasion records must be resolved explicitly.

F₁ = 100 × variables failing at least once / selected variables
F₂ = 100 × failed tests / measured tests
Upper-limit excursion = C/U − 1 when C > U
Lower-limit excursion = L/C − 1 when C < L
nse = ∑ excursions / measured tests
F₃ = 100 nse/(1+nse)
CCME WQI = 100 − √[(F₁² + F₂² + F₃²)/3]

Passing tests contribute zero excursion. Missing tests contribute neither passes nor failures. A zero failing a positive minimum has infinite excursion and the limiting F₃ = 100. An exceeded zero upper limit cannot be ratio-normalized and is rejected. Groups with insufficient tests remain unassessed. Higher CCME values indicate better attainment, the opposite numerical direction from arithmetic WQI/DWQI. CCME does not use arithmetic importance weights or ideals.

The supplied WQI/DWQI worked figures use arithmetic methods; this alternative explains how the calculation changes when the method selector changes. CCME categories assess attainment of selected objectives, not complete drinking-water safety.

Implementation: aquaprovpy/water_quality/wqi.py (ccme_wqi).

Turn index values into classes

Classification is applied to the full-precision score after calculation. Default arithmetic WQI cuts are 25, 50, 75 and 100; default relative-weight WQI/DWQI cuts are 50, 100, 200 and 300. Both use the labels Excellent, Good, Poor, Very Poor and Unsuitable in that order, and both include an exact cut in the lower-valued class. Thus arithmetic WQI = 25 is Excellent, while 25.01 is Good.

CCME uses cuts 45, 65, 80 and 95 with labels Poor, Marginal, Fair, Good and Excellent. Exact cuts enter the next higher class; 95 is Excellent. Custom schemes can change these thresholds, colours and inclusion rules. Nonfinite scores are Unassessed. Always interpret the exported classification scheme rather than assuming colours imply universal thresholds.

Implementation: aquaprovpy/water_quality/common.py (SCHEMES, classify, classification_table).

Quartiles, whiskers and individual extremes

For a set of finite plotted values v, let Q₁, Q₂ and Q₃ be the 25th, 50th and 75th percentiles. AquaProv's NumPy/Matplotlib path uses linear quantiles. If sorted values are v₍₀₎…v₍ₙ₋₁₎, a quantile q lies at index (n−1)q and linearly interpolates neighbouring values (Hyndman & Fan, 1996).

IQR = Q₃ − Q₁
Lower fence = Q₁ − 1.5 IQR;   upper fence = Q₃ + 1.5 IQR

The box spans Q₁ to Q₃ with a median line. Whiskers reach the most extreme observations within the fences, not necessarily the fence coordinates. Values beyond the whiskers remain observations; the plot does not remove them. For values 1, 2, 3, 4, 9, Q₁ = 2, median = 3, Q₃ = 4, and the upper fence is 7, so 9 is beyond the whisker. This descriptive range is not a confidence interval (Tukey, 1977).

The index box plot

The box uses finite WQI or DWQI scores in their original index scale, without z-standardization. Fliers beyond the whiskers remain visible, and distribution_summary and box_outliers record the statistics and source records. These are index outliers under a descriptive rule, not automatically invalid analyses or threshold exceedances. The sample count excludes unassessed composite scores.

Implementation: aquaprovpy/water_quality/plots.py (_box, plot).

Source data & selection#

All 47 source samples; NO3, F, total Cr, Ni and Mn. Metals converted from aqueous ppb to mg/L. WHO 2026 objectives; samples 30 and 31 remain unassessed for the composite index because of missing NO3 or F (Sahoo et al., 2025; World Health Organization, 2026).

Inverse-standard weighted arithmetic WQI; equal-importance weighted DWQI. All ideals are zero; ratings are uncapped. IDW uses power 2 and a 60 × 60 grid, clipped to the sample hull where spatial interpolation is used.

Reproduce it in AquaProv#

  1. Import the prepared Sukinda index CSV. The original source row is retained in SourceRow.
  2. Open WQI & DWQI and choose WQI · Box plot from the plot library.
  3. Select the WHO 2026 guidelines profile. WQI uses weighted arithmetic (inverse-standard weights); DWQI uses the Ramakrishnaiah weighted approach with importance weights of 1. Review NO3, F, Cr_total, Ni and Mn_total in mg/L. Ideals are zero.
  4. Use Sample as the identifier and retain all 47 rows. Samples 30 and 31 have missing selected chemistry, so the composite index stays unassessed.
  5. For maps choose Longitude, Latitude, WGS84 coordinates and EPSG:4326; IDW, power 2, resolution 60. Use a plain background, no extrapolation and the sample-hull mask.
  6. Generate, then inspect the per-parameter ratings, weights, classifications, missing records and spatial grid in Results & methods.

Read the figure#

Lower values indicate better attainment for the arithmetic methods used here. WQI and DWQI use different weights and classification cuts, so compare their method reports as well as their colours. A favourable composite score can coexist with individual exceedances. Campaign comparisons are descriptive, and interpolation does not establish conditions between wells.

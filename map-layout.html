Cartographic tutorial

Finish the cartographic layout

True north, a ground-distance scale, four-sided geographic coordinates, study-boundary coverage and cartographic export.

The finished Sukinda map#

IDW estimates unsampled values from distance-weighted observations (Shepard, 1968). Both screenshots are shown below. Select either image to enlarge it, or use After only for a larger view of the result.

Before

After

The Sukinda worked data are attributed to their associated source publication (Sahoo et al., 2025). The study boundary remains Sukinda_CGWB_Data_Study_Area.kml. All 47 observations lie inside it. The map decoration changes presentation; it does not alter concentrations, interpolation values or extrapolation flags.

1. Establish geography in Data#

  1. Import the Sukinda table. Set X to longitude, Y to latitude and the measurement to TDS.
  2. Choose Source coordinate system → WGS84 longitude / latitude (EPSG:4326). Choose Plain coordinates for an offline background.
  3. Under Study-area boundary, import the supplied KML and enable Use study boundary. Review Use only samples inside boundary and Fill entire boundary (extrapolate).
  4. For interpolation, choose WGS84 longitude / latitude → local metres in Settings. The calculation grid retains metre coordinates even when the map frame displays degrees.

2. Label longitude and latitude on all four sides#

Top and bottom show longitude; left and right show latitude. The interval is angular, not the interpolation cell size. For a narrow panel, use a wider longitude interval so labels do not collide. The two-panel Assessment example uses 0.04° longitude spacing.

3. Add true north and the scale#

ElementWorked settingsInterpretation
North arrowShow north arrow; True north; split chevronTrue north is calculated from the CRS at the symbol position. It is not automatically identical to projected grid north.
Scale barShow scale bar; Kilometres; total length 2; four divisions; white backgroundGround distance is solved at the bar location. It is not obtained by assuming a constant distance per degree.
PlacementNorth: 91% horizontal / 33% vertical; scale: 70% / 10%Placed in the clear southeast part of these study maps. Reposition if your data or extent differ.

Geographic map decoration distinguishes projected coordinates from directions and distances on the reference ellipsoid (Karney, 2013; Snyder, 1987). Regenerate after changing map layout controls. The symbols can also be dragged in the preview; their saved positions and geographic interpretation update. After zooming, verify the scale label: a requested bar can be shortened if it no longer fits.

4. Inspect the complete map inspector#

Use the kriging route for range, partial sill and nugget controls, and the variance route for squared-unit uncertainty. A scale bar is not the color bar; both should be labelled.

5. Preserve the support and uncertainty#

The full-boundary IDW example hatches areas beyond the sample hull; the CSV marks those cells as extrapolated. Kriging and its variance example are restricted to the polygon/hull intersection. Assessment’s fitted map has its native 70 × 70 hull mask; the KML is an added reference outline.

Assessment currently does not expose the Maps module’s cartographic controls. These decorations are applied by the documented Python figure-generation script, using the same cartography functions and the exact local CRS. The actual Assessment sidebar is shown separately. A rotated XYZ surface uses its coordinate axes; pair it with a 2D map instead of reading a planar scale from its perspective view.

6. Export and review at final size#

  1. Check that labels, arrow, scale, points, boundary and color scale remain readable and do not cover important observations.
  2. Export the same view as SVG/PDF and PNG where needed; inspect the exported files independently of the live preview.
  3. Retain the CRS, interpolation parameters, grid masks, source KML and result tables with the figure.
  4. If an online basemap is used, preserve its provider attribution. The supplied examples use no external tiles.

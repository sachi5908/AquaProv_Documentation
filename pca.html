Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

The statistical analysis matrix

Let X contain n retained samples (rows) and p explicitly selected measurements (columns). IDs and coordinate columns should only enter if they are the scientific variables being studied. The default rejects missing measurements and constant columns; explicit drop policies use complete rows across the selected variables and record exclusions. There is no automatic imputation, logarithm, outlier removal or conversion from the ion-unit selector.

For standardized analyses, AquaProv subtracts each variable's mean and divides by its sample standard deviation (Jolliffe & Cadima, 2016):

x̄ⱼ = (1/n)∑ᵢ xᵢⱼ
sⱼ = √[∑ᵢ(xᵢⱼ − x̄ⱼ)²/(n − 1)]
zᵢⱼ = (xᵢⱼ − x̄ⱼ)/sⱼ

Center-only PCA/HCA uses xᵢⱼ − x̄ⱼ without division. The standardized sample heatmap and standardized boxplots always use sample z-scores; the scatter matrix displays original units. For the illustrative values 1, 2, 3, the mean is 2, sample SD is 1 and z-scores are −1, 0, 1. Changing the retained rows changes these preprocessing quantities.

Implementation: aquaprovpy/_publication.py (numeric_frame, standardize), aquaprovpy/multivariate.py.

PCA by singular value decomposition

For the centered (optionally standardized) n × p matrix Z, singular value decomposition gives Z = U D Vᵀ. Let dₖ be singular value k and vₖ its variable direction (Jolliffe & Cadima, 2016):

λₖ = dₖ²/(n − 1)
Scores T = Z Vretained
Loadings L = Vretained diag(√λₖ)
Explained variance (%) = 100λₖ / ∑ⱼλⱼ

The retained component count cannot exceed the matrix rank. AquaProv fixes otherwise arbitrary signs by making the largest absolute eigenvector entry positive. Scores locate samples; loadings describe variable relationships with components. Loadings are not the eigenvectors alone. With standardized data, they are correlations between each variable and unrotated PC scores; covariance PCA loadings retain variable-scale effects.

For optional orthogonal Varimax, each loading row is divided by its retained norm (Kaiser normalization), an orthogonal matrix R maximizes the normalized loading simplicity criterion, then row scales are restored (Kaiser, 1958):

Lrot = L R
Trot = T diag(1/√λₖ) R
Rotated variance (%) for k = 100∑ⱼLrot,jk² / ∑ⱼλⱼ

The rotated score coordinates have unit sample variance; their axis percentages come from rotated loadings. Rotation preserves retained communalities and total retained variance, but its axes are not the original ordered PCs. PCA finds variance directions, not causes or proven source contributions. Review preprocessing, retained variance and sample adequacy with the score plot.

Implementation: aquaprovpy/multivariate.py (pca, varimax, plot).

What the sample-score view plots

Each point is a row of T on PC1–PC2, or a row of Trot on RC1–RC2 when rotated. A point at the origin has zero displayed coordinates; it can still differ on omitted components. Distances summarize differences in the retained subspace of the chosen preprocessing, not distances between wells. Colours and symbols identify sample groups and are not additional PCA variables. Read the two axis percentages together to see how much variance the projection displays.

What the loading heatmap plots

Cell (j, k) is Lⱼₖ, or Lrot,jk after rotation. A diverging colour scale shows signed magnitude, and cell text is rounded for display. The retained communality for variable j is hⱼ² = ∑ₖLⱼₖ². In standardized PCA this is the fraction of that variable's variance represented by the retained components; in covariance PCA it is in squared variable units. A negative loading is an axis direction, not a negative chemical concentration. Full-precision tables retain values behind the displayed rounding.

Eigenvalues, cumulative variance and retention

The scree line plots λₖ for every computed component, including those beyond the chosen retained count. The second axis shows 100∑j≤kλⱼ/∑ⱼλⱼ. With p standardized variables the total variance is p (up to numerical error), so eigenvalue = 1 is an optional retention heuristic; it is not a significance threshold. The scree plot always uses the unrotated eigenvalues even when Varimax is requested. Check a proposed elbow against scientific interpretability and stability.

Correlation-circle coordinates

Each arrow ends at (Lⱼ₁, Lⱼ₂), or the corresponding rotated loadings. This view requires standardized PCA. The unit circle marks x²+y² = 1. The squared arrow length is the portion of variable j's standardized variance represented by these two axes. Short arrows are poorly represented in this plane; their angles can mislead. Similar, opposed and nearly perpendicular arrows suggest positive, negative and weak association only to the extent the displayed plane captures the variables.

The model#

AquaProv mean-centers variables and, by default, standardizes using the sample standard deviation (ddof=1). Full deterministic singular value decomposition yields the components. Turning scaling off requests covariance PCA in the original units.

Xstandardized = U S Vᵀ
Scores = Xstandardized V
λj = Sj² / (n − 1)
Loadings = V diag(√λ)Variance percentages use all available components as the denominator, not only retained components.

Choose the retained component count explicitly; it cannot exceed the numerical data rank. The eigenvalue-one scree line is a heuristic, not an automatic retention rule.

Inspect retained variance#

Optional Varimax rotation#

Varimax is an orthogonal rotation with Kaiser row normalization and a convergence check. Rotated loadings are L × R, with RᵀR = I. Communalities and total retained variance are preserved. Rotated variance is the sum of squared rotated loadings, rather than a new eigendecomposition.

Rotated factor scores = (PC scores / √λ) × RThese rotated score coordinates have unit sample variance. Axes use RC labels.

Do not compare these score values with an undocumented factor-score convention from another package. For a rotated 3D plot, the axis percentages describe variance attributed by rotated loadings, not the variance of the standardized factor-score coordinates.

Rotation reference: Kaiser (1958).

Loadings from the larger Moreno Merino table#

Outputs and interpretation#

Tables include scores, eigenvectors, loadings, variance, preprocessing, analysis data, and communalities; rotation adds its matrix, loadings, scores, and variance. Report displayed variance separately from total retained variance. Use 3D visualization for three-axis views.

A statistical component is not a source label

A high loading can reflect covariation, scaling, or composition constraints. Assigning a pollution source or mineral reaction requires independent chemical and hydrogeological evidence.

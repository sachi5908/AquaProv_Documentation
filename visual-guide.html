From imported data to a finished figure

A detailed illustrated desktop guide to importing, configuring, generating, reviewing and exporting AquaProv analyses.

Start with a complete route#

This illustrated guide follows the actual AquaProv desktop from an empty workspace to saved figures, numerical tables and a reusable project. It accompanies the method references and uses the supplied four datasets. All screenshots are real application captures; the original 45 routes retain their four-tab sidebar references, and the 33 new module routes include generated figures, exact settings and numerical exports.

  1. Import and inspect data
  2. Choose a plot and reproduce its settings
  3. Compare a deliberate setting change
  4. Finish a geographic map
  5. Export figures, results and a saved project
  6. Prepare the evidence accompanying a manuscript

1. Import the source workbook#

  1. Open AquaProv and choose a module. Use the top-toolbar Load data, Ctrl + I, or Data → Import CSV or Excel.
  2. Select Sukinda_CGWB_Data_2024.xlsx from the bundled data folder. CSV files import directly. A worksheet selector appears when an Excel workbook has more than one sheet.
  3. The supplied Sukinda workbook contains one sheet, Selected_47_Samples, which loads automatically. Confirm its name and 47 rows in the Data inspector, then inspect the headers and units. For a workbook with several sheets, choose the intended sheet from the selector rather than assuming the automatically preferred table is correct.

Both screenshots are shown below. Select either image to enlarge it, or use After only for a larger view of the result.

2. Choose the worksheet and review the data#

Check sample identifiers, row counts, measured units, zeros and non-detect qualifiers before plotting. The data preview is read-only. To correct laboratory values or prepare a literature campaign subset, edit a separate source copy, save it, and import the reviewed file. General row filtering is not silently applied by these examples.

The per-plot routes include prepared CSV downloads so that the pictured cohort is reproducible: Liu June 2003 has 19 distinct sites; Yang dry 2005 has 29 distinct wells. Their captions retain the original workbook and selection. W17 time-series dates use the first day of each source month only as a display convention.

The complete panel images on each plot route include controls below the visible scroll area. Scroll the inspector to find them. A collapsed Style section is opened in the Style reference.

4. Generate, change one choice, then inspect#

  1. Turn Auto update off while preparing the example, especially for expensive uncertainty or stability analysis.
  2. Select the plot, review Data, then enter its worked Settings values.
  3. Click the bottom Generate button or press F5. Read exclusions and warnings before interpreting the result.
  4. Change one relevant option. Generate again for calculation, sample appearance, contour or map-layout changes. Use Apply style for pure presentation edits.
  5. Compare the numerical tables and settings as well as the pictures. Save the two variants with different names.

Auto save, Auto update and figure export are separate actions. A newly edited setting is not evidence that the current preview or exported result has been recalculated. See the actual before-and-after comparisons.

5. Confirm the Assessment measurement model#

  1. Use Data → Review measurement mappings…. Confirm major-ion units, trace-element mass units, EC and pH separately.
  2. Map well and time identifiers for repeated-well analysis, and longitude/latitude plus a declared CRS for spatial analysis.
  3. Leave unknown laboratory SDs and reporting limits unspecified. A selected sensitivity scenario is an assumption, not supplied laboratory precision.
  4. Confirm the units and apply the mappings. Generate the chosen Assessment view, review unassessable measurements and preserve the warnings with the results.

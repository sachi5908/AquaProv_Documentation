Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

Coordinates used for distancesInverse-distance weighting (IDW)

Coordinates used for distances

Map projections specify how geographic positions are represented on a plane (Snyder, 1987). Geographic location and distance are separate operations. Projected input uses its source distance units. For WGS84 longitude / latitude → local metres, AquaProv converts degrees to a local metric approximation about the mean longitude λ₀ and latitude φ₀:

x = R(λ − λ₀)cos φ₀;   y = R(φ − φ₀)
R = 6,371,008.8 m; angles in radians
dᵢⱼ = √[(xᵢ − xⱼ)² + (yᵢ − yⱼ)²]

The local approximation is restricted to extents no greater than 3° in either direction and latitudes within ±85°. For larger or more precise studies, choose a suitable projected CRS and consistent distance units. Changing the basemap for display does not change the analysis distance coordinates. Duplicate locations and fewer than three non-collinear observations cannot define these interpolated surfaces without deliberate data preparation.

The current Distance coordinates control also offers automatic UTM/UPS and a custom projected CRS in metres. These transform WGS84 positions through the selected projection before calculating distances; they do not use the local equation above. Enter Analysis CRS for the custom mode, and retain the selected CRS in the calculation record. For existing projected X/Y, Source CRS override declares the original projected system.

Choose Grid definition → Cells per axis for 20–1,000 cells per axis, or Cell size in analysis units for explicit spacing in the analysis coordinate units. The cell-size option has a 1,000,000-point limit. Resolution changes where predictions are evaluated; it does not increase sample support. Colour classification and Surface drawing change the presentation. Retain exported class boundaries when comparing Equal intervals, Quantiles, Natural Breaks (Jenks) or custom classes; large-grid Natural Breaks uses a bounded histogram approximation.

Implementation: aquaprovpy/modules/maps/interpolation.py (planar_coordinates, validate_geometry).

Inverse-distance weighting (IDW)

At target s₀, IDW calculates a normalized weighted average of the selected neighbouring sample values vᵢ. Nearest neighbours → All samples includes all eligible observations; a positive count selects the nearest available observations and includes ties at the cutoff distance. With distance dᵢ = ‖s₀ − sᵢ‖ and positive power p, the sums run over that selected set (Shepard, 1968):

wᵢ = dᵢ−p / ∑ⱼdⱼ−p
v̂(s₀) = ∑ᵢwᵢvᵢ

If the target exactly matches a sample, its observed value is returned. Internally distances are normalized by the nearest distance before exponentiation for numerical stability; normalized weights are unchanged. All weights are nonnegative and sum to 1, so predictions stay within the sample value range. Increasing p favours nearby samples more strongly. At distances 1 and 2 with p = 2, illustrative values 10 and 30 yield (10 + 30/4)/(1 + 1/4) = 14.

The grid is restricted to the convex hull, and to the study-boundary intersection when selected, unless boundary extrapolation is explicitly enabled. Grid resolution changes evaluation density, not the number of observations. IDW supplies no prediction variance or probability. Boundaries clip the display; they are not physical groundwater-flow barriers.

The current geographic gallery exports explicitly enable full-boundary coverage on a 120 × 120 grid. Predictions extend to the supplied Sukinda KML and are clipped at its exact outline; exported tables flag cells beyond the sample hull. The separate Liu seasonal study uses the convex hull of its 19 well locations as a labelled sampling envelope because no surveyed boundary was supplied for that study. Map labels use WGS84 longitude/latitude in decimal degrees, a true-north arrow and a geodesic kilometre scale; interpolation distances remain in local metres.

Implementation: aquaprovpy/modules/maps/interpolation.py (idw, interpolate).

1. Import this worked input#

Module: Maps & contours. Source: Sukinda_CGWB_Data_2024.xlsx / Selected_47_Samples. Prepared records: 47 (Sahoo et al., 2025).

TDS mg/L; IDW power 2; 120 × 120 grid; WGS84 local metres; supplied KML boundary; only samples inside boundary; no basemap. True north; a 2 km WGS84 geodesic scale bar at its displayed location; WGS84 longitude/latitude labels on all four frame borders. Cartographic decoration does not change the observations, predictions or masks. The finished map shows true north, a ground-distance scale in kilometres and WGS84 longitude/latitude on all four borders.

Download this route’s CSV ↓
  1. Open Maps & contours and select IDW contours in the left Plot library. Use its search box to find the plot.
  2. Use Load data in the top toolbar, Ctrl + I, or Data → Dataset → Import CSV or Excel. Import the exact input linked on this page. Select the intended worksheet for a multi-sheet workbook and check the row count and headers in the Data inspector.
  3. Turn Auto update off while entering the worked choices. In the right inspector, open the named tab and click a section heading to expand it; scroll down for the lower controls.
  4. Open Data → Sample locations. Select X = longitude / easting, Y = latitude / northing and the declared Source coordinate system. For the prepared geographic examples, choose Longitude, Latitude and WGS84 longitude / latitude (EPSG:4326). Choose Plain coordinates (no background) for an offline background.
  5. When the worked example uses a boundary, open Data → Study-area boundary → Import KML / KMZ / GeoJSON…, select the linked file and check Use study boundary. Otherwise leave it off. For interpolation, match Use only samples inside boundary and Fill entire boundary (extrapolate) to the worked settings; review the support flags in the exported grid.
  6. Open Settings → Spatial analysis and choose Distance coordinates. The worked local-metre examples use WGS84 longitude / latitude → local metres. The current application also offers WGS84 → automatic UTM / UPS (metres) and WGS84 → custom projected CRS (metres); the latter reveals Analysis CRS. Use a declared projected system for larger areas.
  7. Select IDW contours or a kriging view in the Plot library. In Settings → Spatial analysis, IDW uses IDW power and Nearest neighbours (All samples uses every eligible observation). Ordinary kriging reveals Variogram, range, partial sill and nugget fields, with their units. Enter the worked values; starting defaults are not fitted estimates.
  8. In Settings → Spatial analysis, choose Grid definition → Cells per axis and set Grid cells per axis, or select Cell size in analysis units and enter Cell size (distance units). Use the grid stated for this example.
  9. In Settings → Spatial analysis, use Colour classification for Automatic contour intervals, Equal intervals, Quantiles, Natural Breaks (Jenks) or Custom class boundaries. The custom option reveals Class boundaries. Surface drawing selects filled contours or classified raster cells. Display classes do not change scientific index thresholds.
  10. Settings → Spatial analysis → Apply WGS84 local IDW preset is an optional starting configuration: automatic UTM/UPS, 20-metre cells, 12 nearest observations, power 2, five Natural Breaks classes and raster drawing. It changes several settings together; inspect them before Generate. The older worked figures use their stated grids and distance conversion.
  11. Open Settings → Map layout for the colour scale controls available for this view. Open Settings → Coordinates and grid for frame coordinates, labelled borders, geographic label format, spacing and line design. Under Settings → North arrow, enable Show north arrow and choose Arrow reference → True north (requires source CRS) for geographic north, or Grid north / +Y for the grid direction.
  12. Open Settings → Scale bar, enable Show scale bar, and choose units, total length, divisions, design and position. When the CRS is unknown, declare the distance unit for local X/Y. Generate and check coverage, labels, north and distance scale together.
  13. In Data → Sample locations, select Measurement / point color and optional Label points by. Under Settings → Contour appearance, set lines, labels, sample visibility, width, basemap overlay and fill opacity for contour views.
  14. Click Generate figure or Generate map, or press F5. Open Export → Results & methods to review exclusions, diagnostics, numerical tables and methods before interpreting or exporting the figure.

4. Refine the figure style

  1. In the right inspector, open Settings → Plot settings. Use Show plot title and Manual plot title (optional); leave the title blank for the automatic title. Set title size, weight, style and position here.
  2. Open Style → Publication figure → Typography. Choose the font family and annotation, axis-label, tick and legend sizes. The top toolbar also provides quick typography controls.
  3. In Style → Publication figure, open Labels & ticks to edit axis labels, visibility, limits, ticks and tick formats. Enter the colourbar title in Color scale label (blank = original). Keep quantity and units in labels; blank labels and limits retain the original labels and automatic bounds.
  4. In the same Publication figure panel, open Canvas & grid to set backgrounds, axis borders, grid visibility and layout padding. For geographic frames, use the map-specific Settings → Coordinates and grid controls when available.
  5. Open Style → Publication figure → Legend & color scale. Set Legend position (also draggable), columns, frame and individual Legend items for this plot. Choose Colour scale, Show colourbar and colourbar text sizes for numeric colours. Sample plots need a numeric colour column for a continuous scale; categorical groups use their group colours. Normalize colour scale to 0–1 changes display labels while retaining measurements and scientific classifications.
  6. Open Style → Publication figure → Dimensions & export. Choose Figure sizing → Custom, then set Width (inches) and Height (inches). Review Transparent background and Crop to content; cropping can change exported dimensions.
  7. Click Apply style and inspect the figure at its intended final size. Save preset and Load preset reuse presentation settings. Method, variable, grouping, sample-symbol and interpolation changes require Generate when Auto update is off.

5. Export and preserve

  1. Finish the calculation with Generate figure or Generate map (or F5). Read the warnings, then apply the final style.
  2. Open Export → Figure export. Enter File name, use Save to → Browse to choose your output folder, then select File format and Image resolution (DPI). Use distinct names for alternative results.
  3. Click the format-specific button, such as Export PNG, Export SVG or Export PDF. Open the saved file and check labels, legends, dimensions and the current view. Raster pixel dimensions depend on figure size and DPI.
  4. Open Export → Results & methods. Select a result table to inspect it. Choose Report format: CSV + JSON, Excel (.xlsx), Word (.docx) or PDF (.pdf), then click its export button. Available tables depend on the plot; some geochemical diagrams do not expose a table for every graphical element.
  5. Press Ctrl + S to save the .aquaprov project, including its data and per-plot settings. Keep the original measurements, exported results and final figure together.

Match the worked map domain

The final map uses the supplied Sukinda KML, WGS84 longitude / latitude → local metres and a 120 × 120 grid. Under Data → Study-area boundary, enable Use study boundary, Use only samples inside boundary and Fill entire boundary (extrapolate). For IDW, set Nearest neighbours → All samples. The original 47 sample coordinates lie inside this boundary. The map layout guide describes geographic labels, true north and the 2 km scale. Use the exported support flags to identify predictions outside the sample hull.

Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

The statistical analysis matrixPearson, Spearman and multiple comparisons

The statistical analysis matrix

Let X contain n retained samples (rows) and p explicitly selected measurements (columns). IDs and coordinate columns should only enter if they are the scientific variables being studied. The default rejects missing measurements and constant columns; explicit drop policies use complete rows across the selected variables and record exclusions. There is no automatic imputation, logarithm, outlier removal or conversion from the ion-unit selector.

For standardized analyses, AquaProv subtracts each variable's mean and divides by its sample standard deviation (Jolliffe & Cadima, 2016):

x̄ⱼ = (1/n)∑ᵢ xᵢⱼ
sⱼ = √[∑ᵢ(xᵢⱼ − x̄ⱼ)²/(n − 1)]
zᵢⱼ = (xᵢⱼ − x̄ⱼ)/sⱼ

Center-only PCA/HCA uses xᵢⱼ − x̄ⱼ without division. The standardized sample heatmap and standardized boxplots always use sample z-scores; the scatter matrix displays original units. For the illustrative values 1, 2, 3, the mean is 2, sample SD is 1 and z-scores are −1, 0, 1. Changing the retained rows changes these preprocessing quantities.

Implementation: aquaprovpy/_publication.py (numeric_frame, standardize), aquaprovpy/multivariate.py.

Pearson, Spearman and multiple comparisons

Pearson correlation measures linear association between two retained variables (Pearson, 1895):

rxy = ∑ᵢ(xᵢ − x̄)(yᵢ − ȳ) / √[∑ᵢ(xᵢ − x̄)² · ∑ᵢ(yᵢ − ȳ)²]

Spearman correlation applies Pearson's calculation to within-variable ranks, with average ranks for ties. It measures monotonic association. Both range from −1 to +1; neither proves causation. Every pair uses the same complete-case analysis rows, so the exported n_pairs is constant across the matrix. It is not pairwise deletion (Spearman, 1904).

SciPy supplies two-sided p-values; Spearman uses its asymptotic approximation. When FDR display is selected, AquaProv applies Benjamini–Hochberg once across m = p(p−1)/2 unique off-diagonal tests. With ordered p-values p(k) (Benjamini & Hochberg, 1995):

q(k) = min[1, minj≥k(m · p(j)/j)]

The lower-triangle heatmap displays correlation, with one star below 0.05 and two below 0.01 using either raw p or adjusted q as selected. Diagonal coefficients are 1 and have no test. Small samples, repeated wells and temporal/spatial dependence can invalidate ordinary significance interpretations; changing the star display does not change the coefficients.

Implementation: aquaprovpy/multivariate.py (correlation, plot).

1. Import this worked input#

Module: Statistics. Source: data_Yang_et_al_2020.xlsx / Data. Prepared records: 29 (Yang et al., 2020).

Dry-season 2005 campaign: 29 distinct wells. Variables: pH, Ca, Mg, Na, K, HCO3, Cl, SO4. No imputation, log transform, or outlier removal. Literature concentration units are assumed mg/L; verify the primary source. Spearman rank coefficients; raw descriptive p-values.

Download this route’s CSV ↓
  1. Open Statistics and choose Spearman correlation in the left Plot library.
  2. Choose Data → Import CSV or Excel and import the prepared CSV above. Confirm 29 rows. This CSV is a declared working copy; the original dataset is retained in Datasets.
  3. Keep Auto update off while entering settings. Check the Data panel below, including units, coordinates or measurement mappings when present.

4. Refine the Style panel#

Open Typography, Labels & ticks, Canvas & grid, Legend & color scale, or Dimensions & export. Use the illustrated Style reference for all five sections. Apply presentation changes, then inspect labels, legend and final physical dimensions. Sample grouping/symbol changes belong to Settings and require Generate.

5. Export and preserve#

  1. Choose a descriptive file name and an output folder you control. Use separate names for alternatives.
  2. Select PNG/TIFF for raster output or SVG/PDF for vector-compatible output. Set DPI for raster output; verify final dimensions.
  3. Click the named Export button. Save numerical Results & methods separately when available.
  4. Save the .aquaprov project.

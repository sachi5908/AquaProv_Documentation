Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

XYZ scatter in source-variable coordinates

XYZ scatter in source-variable coordinates

A three-dimensional scatterplot represents an observation by its position on three numerical axes (Cleveland, 1993). Each point is exactly (Xᵢ, Yᵢ, Zᵢ) from three selected numeric columns. Colour follows Z over the measurement range. AquaProv applies no CRS conversion, standardization, regression or PCA in this mode. All coordinate/measurement values must be finite; the scientific meaning of distance depends on the chosen variables and their units. Reference lines to the coordinate planes and camera changes are graphical aids, not additional measurements.

Implementation: aquaprovpy/modules/three_d/plots.py (plot_xyz).

1. Import this worked input#

Module: 3D visualization. Source: data_Liu_et_al_2021.xlsx / Data. Prepared records: 19 (Liu et al., 2021).

June 2003 campaign: 19 distinct sites. 19 June 2003 sites; Ca, Mg and HCO3 are three measured chemistry axes, not spatial coordinates. Literature concentrations assumed mg/L; orthographic camera, no fitted surface.

Download this route’s CSV ↓
  1. Open 3D visualization and choose XYZ sample scatter in the left Plot library.
  2. Choose Data → Import CSV or Excel and import the prepared CSV above. Confirm 19 rows. This CSV is a declared working copy; the original dataset is retained in Datasets.
  3. Keep Auto update off while entering settings. Check the Data panel below, including units, coordinates or measurement mappings when present.

Confirm the selected input and row count; this view has no extra Data controls to configure.

4. Refine the Style panel#

Open Typography, Labels & ticks, Canvas & grid, Legend & color scale, or Dimensions & export. Use the illustrated Style reference for all five sections. Apply presentation changes, then inspect labels, legend and final physical dimensions. Sample grouping/symbol changes belong to Settings and require Generate.

5. Export and preserve#

  1. Choose a descriptive file name and an output folder you control. Use separate names for alternatives.
  2. Select PNG/TIFF for raster output or SVG/PDF for vector-compatible output. Set DPI for raster output; verify final dimensions.
  3. Click the named Export button. Save numerical Results & methods separately when available.
  4. Save the .aquaprov project.

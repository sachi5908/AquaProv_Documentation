Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

Conditional Monte Carlo measurement propagationConditional probability of an upper-threshold exceedanceFollow-up assay priorities and the budget rule

Conditional Monte Carlo measurement propagation

Monte Carlo propagation evaluates an output model repeatedly using draws from specified input distributions (Joint Committee for Guides in Metrology, 2008). For a positive detected concentration with supplied mean m and SD s, AquaProv uses a moment-matched lognormal marginal. Laboratory mode uses mapped SDs, scenario mode uses s = r·m for the selected relative SD r, and fixed mode uses a constant:

σ²log = ln[1 + (s/m)²]
μlog = ln(m) − σ²log/2
C* = exp(μlog + σlogZ),   Z ∼ Normal(0,1)

An optional shared log-error correlation ρ uses Zᵢ = √ρ Z₀ + √(1−ρ)εᵢ, with independent standard normal Z₀ and εᵢ. This is a specified log-error scenario, not an estimated concentration correlation. Zero with positive SD has no supported nonnegative moment-matched distribution; a missing laboratory SD is unassessed in laboratory mode.

Each draw is converted to equivalents and passed through the same SAR, sodium-percentage and graphical classification formulas as the deterministic diagrams. Reported intervals are the finite-draw 2.5th, 50th and 97.5th percentiles. Class and threshold probabilities are indicator frequencies:

P̂(event) = (1/B)∑b=1…B 1(event in draw b)
Monte Carlo SE = √[P̂(1−P̂)/B]

Wilson intervals describe binomial sampling precision for an estimated probability (Wilson, 1927). The exported 95% Wilson bounds and split-half difference describe simulation precision. They do not quantify whether the chosen SDs, distributions or correlation are scientifically correct. The irrigation interval view plots SAR and Na% intervals by sample; class probabilities are in the result tables. All conclusions are conditional on the chosen measurement and censoring model.

Implementation: aquaprovpy/assessment/uncertainty.py (draw_observation, draw_group, interval, probability, propagate).

Conditional probability of an upper-threshold exceedance

Chemical guideline values provide substance-specific comparison levels that require interpretation in their health and exposure context (World Health Organization, 2026). For selected species concentration C and a named threshold H in mg/L of that same species, the event is strictly C > H. Its probability is the fraction of simulation draws above H. A draw exactly equal to H is not an exceedance. For example, 120 exceedances among 2,000 draws give P̂ = 0.06 and Monte Carlo SE ≈ 0.00531.

The screening figure shows up to 30 assessable assay probabilities in its left panel; its right histogram uses all assessable probabilities with bins from 0 to 1. No supported distribution means unassessed, not P = 0. The default versioned assessment profile is WHO-2022-selected-chemicals-v1 (NO₃ 50, F 1.5, total Cr 0.05 and Ni 0.07 mg/L); it is distinct from the configurable WQI standards profiles. Review the actual exported profile and reporting basis.

For censored observations, logical bounds can sometimes be reported without a distribution: C < L with L ≤ H implies no exceedance under that reporting inequality; C > L with L > H implies exceedance. Otherwise the probability may remain anywhere in [0,1]. Those bounds assume a valid reporting limit. Screening a few chemical species does not establish overall drinking-water safety.

Implementation: aquaprovpy/assessment/uncertainty.py (WHO_SCREENING, propagate), aquaprovpy/assessment/engine.py.

Follow-up assay priorities and the budget rule

The default ambiguity priority is largest near P = 0.5 and zero at P = 0 or 1:

Ambiguity = min(P, 1 − P)
Priority score = ambiguity / assay cost
Budget eligibility: rank × equal assay cost ≤ budget, with priority score > 0

Candidates are sorted by descending score, then ascending relative threshold margin |median−H|/H, source row and analyte. The left panel displays exceedance probabilities in this priority order; the right displays scores, with budget-eligible assays highlighted. High exceedance probability and high uncertainty are different reasons to act. This default score is a review heuristic, not a health-risk or value-of-information calculation.

The optional EVSI method uses a normal current log concentration X ∼ N(μ,σ²) and an independent follow-up log assay Y|X ∼ N(X,τ²). Its posterior has gain k = σ²/(σ²+τ²), mean μ′ = μ+k(Y−μ), and variance σ′² = (1−k)σ². With unit loss for an incorrect binary threshold decision:

Current risk = min(P, 1−P)
EVSI = current risk − EY[min(P′, 1−P′)]
EVSI priority = EVSI / assay cost

The expectation uses numerical Gaussian integration in expected_value. Equal assay costs, stable chemistry, additive binary loss and no information sharing across assays are assumed. Unsupported censored current distributions cannot receive this EVSI rank. Inspect excluded assays as well as the ranked list.

Implementation: aquaprovpy/assessment/uncertainty.py (propagate), aquaprovpy/assessment/decision.py (posterior_log_parameters, expected_value).

1. Import this worked input#

Module: Assessment. Source: Sukinda_CGWB_Data_2024.xlsx / Selected_47_Samples. Prepared records: 47 (Sahoo et al., 2025).

All 47 source records. All 47 Sukinda rows; explicitly mapped source units. Positive concentrations use an assumed 5% relative-SD lognormal sensitivity scenario, 2,000 draws, seed 42, independent errors. These SDs are not laboratory estimates. WHO-2022-selected-chemicals-v1: NO3, F, total Cr and Ni only; not complete potability assessment. Budget 10 cost units; equal assay cost 1. Gold indicates selected ambiguous assays; ranking is a follow-up heuristic.

Download this route’s CSV ↓
  1. Open Assessment and select Follow-up assay priorities in the left Plot library. Use its search box to find the plot.
  2. Use Load data in the top toolbar, Ctrl + I, or Data → Dataset → Import CSV or Excel. Import the exact input linked on this page. Select the intended worksheet for a multi-sheet workbook and check the row count and headers in the Data inspector.
  3. Turn Auto update off while entering the worked choices. In the right inspector, open the named tab and click a section heading to expand it; scroll down for the lower controls.
  4. Open Data → Measurement model → Review measurement mappings…. In the measurement editor, map each analyte, source column, unit, chemical basis, and available SD or detection-limit fields. Map sample, well, time and coordinates separately in metadata; confirm the reviewed mappings.
  5. In Data → Measurement model, review Subset column, Keep rows equal to and Use first source record per well in the selected subset. Keep the documented cohort; repeated-well inference needs repeated observations.
  6. Open Settings → Assessment settings. Enter the worked choices listed below. Check the chart/view selector when this analysis offers several outputs.
  7. Review Uncertainty model, any Scenario relative SD (%), the non-detect method, Monte Carlo draws and random seed where exposed. A sensitivity scenario describes an explicit assumption; it does not supply laboratory precision. Threshold screening and assay priorities also need the chosen profile and budget.
  8. Click Generate figure or Generate map, or press F5. Open Export → Results & methods to review exclusions, diagnostics, numerical tables and methods before interpreting or exporting the figure.

3. Generate and review the result

Click Generate figure or Generate map, or press F5. Inspect the figure, then open Export → Results & methods for available tables and warnings. Use the final plot preview in the Gallery to review this example.

Interpret the result using the method guide. Inspect numerical outputs under Export → Results & methods. Available result tables include: metric_intervals, class_probabilities, threshold_probabilities, assay_priorities, excluded_from_propagation, quality_by_sample, measurement_status, observations, normalized_measurements, flagged_observations, selection_exclusions.

4. Refine the figure style

  1. In the right inspector, open Settings → Plot settings. Use Show plot title and Manual plot title (optional); leave the title blank for the automatic title. Set title size, weight, style and position here.
  2. Open Style → Publication figure → Typography. Choose the font family and annotation, axis-label, tick and legend sizes. The top toolbar also provides quick typography controls.
  3. In Style → Publication figure, open Labels & ticks to edit axis labels, visibility, limits, ticks and tick formats. Enter the colourbar title in Color scale label (blank = original). Keep quantity and units in labels; blank labels and limits retain the original labels and automatic bounds.
  4. In the same Publication figure panel, open Canvas & grid to set backgrounds, axis borders, grid visibility and layout padding. For geographic frames, use the map-specific Settings → Coordinates and grid controls when available.
  5. Open Style → Publication figure → Legend & color scale. Set Legend position (also draggable), columns, frame and individual Legend items for this plot. Choose Colour scale, Show colourbar and colourbar text sizes for numeric colours. Sample plots need a numeric colour column for a continuous scale; categorical groups use their group colours. Normalize colour scale to 0–1 changes display labels while retaining measurements and scientific classifications.
  6. Open Style → Publication figure → Dimensions & export. Choose Figure sizing → Custom, then set Width (inches) and Height (inches). Review Transparent background and Crop to content; cropping can change exported dimensions.
  7. Click Apply style and inspect the figure at its intended final size. Save preset and Load preset reuse presentation settings. Method, variable, grouping, sample-symbol and interpolation changes require Generate when Auto update is off.

5. Export and preserve

  1. Finish the calculation with Generate figure or Generate map (or F5). Read the warnings, then apply the final style.
  2. Open Export → Figure export. Enter File name, use Save to → Browse to choose your output folder, then select File format and Image resolution (DPI). Use distinct names for alternative results.
  3. Click the format-specific button, such as Export PNG, Export SVG or Export PDF. Open the saved file and check labels, legends, dimensions and the current view. Raster pixel dimensions depend on figure size and DPI.
  4. Open Export → Results & methods. Select a result table to inspect it. Choose Report format: CSV + JSON, Excel (.xlsx), Word (.docx) or PDF (.pdf), then click its export button. Available tables depend on the plot; some geochemical diagrams do not expose a table for every graphical element.
  5. Press Ctrl + S to save the .aquaprov project, including its data and per-plot settings. Keep the original measurements, exported results and final figure together.

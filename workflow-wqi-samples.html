Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

Calculate the index before drawing the plot

Weighted indices combine parameter ratings after specifying standards and relative contributions (Ramakrishnaiah et al., 2009). For each sample and selected parameter i, first convert concentration Cᵢ into the canonical unit and named chemical basis of its standard. Let Iᵢ be the ideal, Sᵢ the rating standard, and Wᵢ the normalized weight. The arithmetic index is:

Index = ∑ᵢWᵢqᵢ;   ∑ᵢWᵢ = 1
Ratio rating: qᵢ = 100Cᵢ/Sᵢ
Ideal rating: qᵢ = 100(Cᵢ − Iᵢ)/(Sᵢ − Iᵢ)

For a two-sided rating with Lᵢ < Iᵢ < Uᵢ, use qᵢ = 100(Cᵢ−Iᵢ)/(Uᵢ−Iᵢ) above the ideal, and qᵢ = 100(Iᵢ−Cᵢ)/(Iᵢ−Lᵢ) below it. This differs from the signed ideal formula, which may produce negative ratings. An ideal of zero makes the upper-standard ideal rating equal to the ratio rating. Individual ratings and contributions Wᵢqᵢ are exported.

Selected method Normalized weights and meaning
Weighted arithmetic WQI (inverse-standard weights) Wᵢ = (1/Sᵢ)/∑ⱼ(1/Sⱼ), using canonical standard units
Relative-weight groundwater WQI Wᵢ = wᵢ/∑ⱼwⱼ from the chosen positive importance weights
Weighted DWQI The same weighted-sum form with independently chosen DWQI parameters, ratings and importance weights
Custom weighted DWQI The explicitly configured weights, ratings, limits and classification define the calculation

The original NSF water-quality index combined ratings for selected water-quality characteristics (Brown et al., 1970). The weighted arithmetic option implements this inverse-standard convention; it does not reproduce the original NSF nine-parameter rating curves. Inverse-standard weights depend on the declared canonical units, so input and standard unit conversion must precede weighting. DWQI has no single universal formula. A method name alone is insufficient to reproduce a result.

Illustrative calculation: with ratio ratings C = (10, 0.75) mg/L and S = (50, 1.5) mg/L, q = (20, 50). Inverse-standard weights are (3/103, 100/103), giving WQI ≈ 49.126. Equal importance weights instead give 35. This is a two-parameter arithmetic illustration, not a validated drinking-water assessment or CCME dataset.

An arithmetic score requires every selected measurement in the row. If any are missing, the score remains unassessed; weights are not renormalized to the available subset. A favourable composite can coexist with an individual exceedance. Review selected hazards, standards edition, per-parameter compliance and missing counts.

Implementation: aquaprovpy/water_quality/common.py (unit_factor, ratings, aggregate_arithmetic), aquaprovpy/water_quality/wqi.py, aquaprovpy/water_quality/dwqi.py.

Alternative WQI: CCME scope, frequency and amplitude

The CCME index combines scope, frequency and amplitude of guideline nonattainment; the 2017 manual recommends more than the original four-parameter minimum when suitable monitoring data are available (Canadian Council of Ministers of the Environment, 2001, 2017). If CCME is selected, AquaProv calculates one WQI per site/period from repeated occasions rather than one arithmetic score per row. It requires at least four selected variables and at least four measured occasions per variable in each site/period. Duplicate site/period/occasion records must be resolved explicitly.

F₁ = 100 × variables failing at least once / selected variables
F₂ = 100 × failed tests / measured tests
Upper-limit excursion = C/U − 1 when C > U
Lower-limit excursion = L/C − 1 when C < L
nse = ∑ excursions / measured tests
F₃ = 100 nse/(1+nse)
CCME WQI = 100 − √[(F₁² + F₂² + F₃²)/3]

Passing tests contribute zero excursion. Missing tests contribute neither passes nor failures. A zero failing a positive minimum has infinite excursion and the limiting F₃ = 100. An exceeded zero upper limit cannot be ratio-normalized and is rejected. Groups with insufficient tests remain unassessed. Higher CCME values indicate better attainment, the opposite numerical direction from arithmetic WQI/DWQI. CCME does not use arithmetic importance weights or ideals.

The supplied WQI/DWQI worked figures use arithmetic methods; this alternative explains how the calculation changes when the method selector changes. CCME categories assess attainment of selected objectives, not complete drinking-water safety.

Implementation: aquaprovpy/water_quality/wqi.py (ccme_wqi).

Turn index values into classes

Classification is applied to the full-precision score after calculation. Default arithmetic WQI cuts are 25, 50, 75 and 100; default relative-weight WQI/DWQI cuts are 50, 100, 200 and 300. Both use the labels Excellent, Good, Poor, Very Poor and Unsuitable in that order, and both include an exact cut in the lower-valued class. Thus arithmetic WQI = 25 is Excellent, while 25.01 is Good.

CCME uses cuts 45, 65, 80 and 95 with labels Poor, Marginal, Fair, Good and Excellent. Exact cuts enter the next higher class; 95 is Excellent. Custom schemes can change these thresholds, colours and inclusion rules. Nonfinite scores are Unassessed. Always interpret the exported classification scheme rather than assuming colours imply universal thresholds.

Implementation: aquaprovpy/water_quality/common.py (SCHEMES, classify, classification_table).

Sampling points and values

This route draws the calculated index at each retained sample/site-period coordinate. It does not create a spatial grid. Marker colour and labels identify the score and its classification under the chosen method. Empty space between points has no predicted value. Validate coordinate mapping and inspect unassessed samples before interpreting apparent spatial clusters.

Implementation: aquaprovpy/water_quality/plots.py (plot, view='samples' skips _grid).

The worked figure#

Source data & selection#

All 47 source samples; NO3, F, total Cr, Ni and Mn. Metals converted from aqueous ppb to mg/L. WHO 2026 objectives; samples 30 and 31 remain unassessed for the composite index because of missing NO3 or F (Sahoo et al., 2025; World Health Organization, 2026).

Inverse-standard weighted arithmetic WQI; equal-importance weighted DWQI. All ideals are zero; ratings are uncapped. IDW uses power 2 and a 120 × 120 grid, clipped to the full supplied KML or the documented Liu sampling envelope where spatial interpolation is used.

Reproduce it in AquaProv

  1. Open WQI & DWQI and select WQI · Sampling points and values in the left Plot library. Use its search box to find the plot.
  2. Use Load data in the top toolbar, Ctrl + I, or Data → Dataset → Import CSV or Excel. Import the exact input linked on this page. Select the intended worksheet for a multi-sheet workbook and check the row count and headers in the Data inspector.
  3. Turn Auto update off while entering the worked choices. In the right inspector, open the named tab and click a section heading to expand it; scroll down for the lower controls.
  4. The selected WQI plot determines the index profile. Open Settings → Index calculation and set Methodology to Weighted arithmetic WQI (inverse-standard weights). Choose the WHO GDWQ entry dated 2026 in Standards database and set Limit category → Guideline.
  5. For WQI, click Review parameters, weights, units and limits…. Select NO3, F, Cr_total, Ni and Mn_total, map their input columns and mg/L units, and use zero ideals. WQI derives inverse-standard weights. Review Edit classification thresholds and colours….
  6. Open Data → Sampling sites and seasons. Use Sample / site column → Sample and retain the 47 source rows. Missing selected chemistry leaves samples 30 and 31 unassessed; weights are not renormalized.
  7. Open Data → Sample locations. Select X = longitude / easting, Y = latitude / northing and the declared Source coordinate system. For the prepared geographic examples, choose Longitude, Latitude and WGS84 longitude / latitude (EPSG:4326). Choose Plain coordinates (no background) for an offline background.
  8. When the worked example uses a boundary, open Data → Study-area boundary → Import KML / KMZ / GeoJSON…, select the linked file and check Use study boundary. Otherwise leave it off. For interpolation, match Use only samples inside boundary and Fill entire boundary (extrapolate) to the worked settings; review the support flags in the exported grid.
  9. Open Settings → Index interpolation and choose Distance coordinates. The worked local-metre examples use WGS84 longitude / latitude → local metres. The current application also offers WGS84 → automatic UTM / UPS (metres) and WGS84 → custom projected CRS (metres); the latter reveals Analysis CRS. Use a declared projected system for larger areas.
  10. Open Settings → Index figure appearance for the colour scale controls available for this view. Open Settings → Coordinates and grid for frame coordinates, labelled borders, geographic label format, spacing and line design. Under Settings → North arrow, enable Show north arrow and choose Arrow reference → True north (requires source CRS) for geographic north, or Grid north / +Y for the grid direction.
  11. Open Settings → Scale bar, enable Show scale bar, and choose units, total length, divisions, design and position. When the CRS is unknown, declare the distance unit for local X/Y. Generate and check coverage, labels, north and distance scale together.
  12. Open Settings → Point and plot appearance for point visibility, colours, fills, outlines, markers, size and opacity. Open Point labels for content, font, colour, decimal places, wrapping, leader lines and text halo. Automatic point colours use the numeric scale on sample-only maps and the chosen fill for overlays.
  13. For CCME instead of the arithmetic worked method, first select a WQI view in the Plot library. Choose Settings → Index calculation → Methodology → CCME WQI 1.0 (2001), then map Data → Sampling sites and seasons → Sampling occasion (CCME). Review the required variables and distinct occasions; CCME yields a site/period index and uses a different score direction.
  14. Click Generate figure or Generate map, or press F5. Open Export → Results & methods to review exclusions, diagnostics, numerical tables and methods before interpreting or exporting the figure.

Read the figure#

Lower values indicate better attainment for the arithmetic methods used here. WQI and DWQI use different weights and classification cuts, so compare their method reports as well as their colours. A favourable composite score can coexist with individual exceedances. Campaign comparisons are descriptive, and interpolation does not establish conditions between wells.

Refine the figure style

  1. In the right inspector, open Settings → Plot settings. Use Show plot title and Manual plot title (optional); leave the title blank for the automatic title. Set title size, weight, style and position here.
  2. Open Style → Publication figure → Typography. Choose the font family and annotation, axis-label, tick and legend sizes. The top toolbar also provides quick typography controls.
  3. In Style → Publication figure, open Labels & ticks to edit axis labels, visibility, limits, ticks and tick formats. Enter the colourbar title in Color scale label (blank = original). Keep quantity and units in labels; blank labels and limits retain the original labels and automatic bounds.
  4. In the same Publication figure panel, open Canvas & grid to set backgrounds, axis borders, grid visibility and layout padding. For geographic frames, use the map-specific Settings → Coordinates and grid controls when available.
  5. Open Style → Publication figure → Legend & color scale. Set Legend position (also draggable), columns, frame and individual Legend items for this plot. Choose Colour scale, Show colourbar and colourbar text sizes for numeric colours. Sample plots need a numeric colour column for a continuous scale; categorical groups use their group colours. Normalize colour scale to 0–1 changes display labels while retaining measurements and scientific classifications.
  6. Open Style → Publication figure → Dimensions & export. Choose Figure sizing → Custom, then set Width (inches) and Height (inches). Review Transparent background and Crop to content; cropping can change exported dimensions.
  7. Click Apply style and inspect the figure at its intended final size. Save preset and Load preset reuse presentation settings. Method, variable, grouping, sample-symbol and interpolation changes require Generate when Auto update is off.

Export and preserve

  1. Finish the calculation with Generate figure or Generate map (or F5). Read the warnings, then apply the final style.
  2. Open Export → Figure export. Enter File name, use Save to → Browse to choose your output folder, then select File format and Image resolution (DPI). Use distinct names for alternative results.
  3. Click the format-specific button, such as Export PNG, Export SVG or Export PDF. Open the saved file and check labels, legends, dimensions and the current view. Raster pixel dimensions depend on figure size and DPI.
  4. Open Export → Results & methods. Select a result table to inspect it. Choose Report format: CSV + JSON, Excel (.xlsx), Word (.docx) or PDF (.pdf), then click its export button. Available tables depend on the plot; some geochemical diagrams do not expose a table for every graphical element.
  5. Press Ctrl + S to save the .aquaprov project, including its data and per-plot settings. Keep the original measurements, exported results and final figure together.

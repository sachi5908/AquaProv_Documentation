Style, export and reproduce a figure

Set figure styles and dimensions, then export the generated figure.

1. Inspect the five Style sections#

SectionWhat you can adjustReview before export
TypographyFonts, title/label/tick sizes and emphasisReadable at final printed size; distinguish scientific notation from decorative text.
Labels & ticksAxis labels and tick rotationRetain chemical species, units and the actual plotted quantity.
Canvas & gridBackgrounds, borders and gridUse sufficient contrast without obscuring the observations.
Legend & color scaleLegend position, scalar color map and color-scale labelSequential palettes for ordered values; show units and distinguish SD from variance.

The screenshots show every expandable Style subsection. Use Apply style to update presentation. The typography example in the comparison guide verifies that the numerical tables stay unchanged.

2. Choose physical size and output format#

Set width/height for the intended final artwork. As a practical example, 7.1 inches is approximately 180 mm; a 300 DPI raster at that width has 2,130 pixels before optional tight cropping. This is an example working size, not an asserted EM&S requirement. Check the current publisher artwork instructions for the submission type.

OutputWhen usefulWhat DPI means
SVG or PDFText, axes, diagrams and other vector-compatible artworkDPI affects embedded raster content, not the resolution of vector paths.
PNGLossless review images and raster artworkPixel dimensions depend on physical size × DPI; inspect small text at final size.
TIFFWhen the publisher requests a lossless raster formatSet the required physical size and resolution, then verify the exported file.
JPGOnly when appropriate for photographic/raster contentLossy compression can blur fine labels and lines.

Tight cropping can change pixel bounds. Transparent backgrounds should be checked against the actual page background. Keep the source project and a lossless master.

3. Export the actual generated figure#

  1. Generate the final analysis and inspect its warnings. Apply the intended presentation settings.
  2. Open Export. Enter a meaningful File name and choose Save to.
  3. Select the figure format and DPI. Click the matching Export PNG / SVG / … button.
  4. Read the completion message and open the exported file. If prompted about replacement, check the filename before overwriting.

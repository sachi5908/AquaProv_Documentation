# AquaProv Documentation

Online documentation for **AquaProv V. 1.0** (Aquatic Geochemistry & Provenance),
an open-source desktop application for water-chemistry analysis, geochemical
diagrams, statistics, spatial mapping and 3D visualization.

**[Open the documentation website](https://sachi5908.github.io/AquaProv_Documentation/)**

This repository contains the static documentation website. The application
source is maintained in [sachi5908/AquaProv](https://github.com/sachi5908/AquaProv).

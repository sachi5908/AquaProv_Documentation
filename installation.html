System Requirements#

Use the table below to plan a Windows computer for AquaProv. CPU and RAM values are practical guidelines; memory use and processing time depend on dataset size, interpolation settings and the number of uncertainty simulations.

Minimum and recommended system requirements for the AquaProv Windows desktop application.
ComponentMinimumRecommended
Operating systemWindows 10 version 1809 or newer, 64-bitWindows 11 64-bit
CPUx86-64, 2 cores, 2.0 GHzx86-64, 6 or more cores, 3.0 GHz or faster
Installed RAM8 GB16 GB or more; allow additional memory for large datasets and uncertainty ensembles of 10,000 or more draws
Free disk space500 MB for the standalone application; allow at least 2 GB for Python and dependencies when running from source2 GB or more, plus space for datasets, saved projects, exported figures and reports
Screen sizeNo fixed screen diagonal; the display must provide the usable resolution below16.1-inch screen or larger for viewing plots and settings together
Display resolution1100 × 720 usable desktop pixels for the analysis workspace1920 × 1080 or higher; allow room for operating-system controls and display scaling
Colour depth24-bit colour (typically a 32-bit display mode)32-bit display mode
Graphics hardwareNo dedicated GPU required; Matplotlib renders figures on the CPU, including 3D viewsIntegrated or dedicated graphics for the display; AquaProv does not require GPU acceleration for computation
Python (source only)Python 3.10 or newer, 64-bitPython 3.10.11, 64-bit (used for the verified Windows build)

The standalone Windows application includes Python and its dependencies. Source installation also needs the packages listed in requirements.txt. The macOS and Linux source instructions below include their platform-specific setup notes.

Windows Installer#

For 64-bit Windows 10 (version 1809 or newer) and Windows 11. Python is included.

Step 1: Download

Save AquaProv-Setup-1.0-x64.exe to your Downloads folder.

Download for Windows

Step 2: Open Setup

Double-click the downloaded file. If asked, choose Install for all users and approve the administrator prompt. On the welcome screen, click Next.

Step 3: Accept the Licence

Read the licence. If you agree, select I accept the agreement and click Next.

Step 4: Choose Options

Keep the suggested installation folder if shown. Tick Create a desktop shortcut if wanted, then click Next.

Step 5: Install

Review your choices and click Install.

Step 6: Wait

Wait for Setup to finish copying the files.

Step 7: Launch AquaProv

Leave Launch AquaProv checked and click Finish.

Step 8: Open It Again

Use the AquaProv Desktop shortcut or search for AquaProv in the Windows Start menu.

Python Source: Before You Begin#

Follow the sections below if you want to run AquaProv from its Python source folder. Windows installer users can continue directly to Data Preparation.

  • Install Python 3.10 or newer: Download Python from python.org. On Windows, use the 64-bit installer and select Add Python to PATH if that option is shown. Complete the installation before opening a new terminal.
  • Use a desktop computer: AquaProv opens a graphical application window. The supplied application and workflows are developed and checked on Windows; the macOS and Linux sections below describe source setup and have not been validated on those systems.
  • Connect to the internet: Python packages need to be downloaded during installation. Desktop analysis and these local guides work offline; online map backgrounds need an internet connection.

This tutorial installs packages directly into the Python installation you use to launch AquaProv. You do not need to create or activate a virtual environment.

Get the AquaProv Source Folder#

Download the source from the AquaProv repository, then extract it.

Locate the folder containing main.py, requirements.txt and aquaprovpy/. Keep the entire folder together. The examples below call this folder AquaProv; use its actual name and location on your computer.

The separate AquaProv_Documentation repository contains the website. Download the application source to run AquaProv.

Windows: Run from Python Source#

Step 1: Prepare the Folder

Extract the complete AquaProv source folder onto your Desktop or another drive, such as D:. Open the extracted folder and check that you can see main.py and requirements.txt.

Step 2: Open the Command Prompt

Press the Windows key, type cmd, and press Enter. In the Command Prompt window, check that Python is available:

Command Prompt
python --version

You should see Python 3.10 or a newer version. If Windows cannot find Python, follow Troubleshoot Startup below.

Step 3: Navigate to Your Folder

The cd command means change directory. Type cd /d followed by your AquaProv folder path in quotation marks, then press Enter. The /d option also changes drives.

For example, if you extracted AquaProv onto your Desktop:

Command Prompt · Desktop example
cd /d "%USERPROFILE%\Desktop\AquaProv"

If your folder is on the D: drive, use this example instead:

Command Prompt · D: drive example
cd /d "D:\AquaProv"

Use only the command that matches your folder. If your Desktop is inside OneDrive or the extracted folder is called AquaProv-main, open it in File Explorer, copy its address, and use that full path between the quotation marks.

Step 4: Install Required Packages

From the same Command Prompt window, run the command below. It installs the packages listed in AquaProv's requirements.txt, including the interface and scientific libraries.

Command Prompt
python -m pip install -r requirements.txt

Installation may take a few minutes. Text will scroll through the window as packages download and install. Wait until the command prompt returns; if an error appears, resolve it before continuing.

Step 5: Launch AquaProv

Type the following command and press Enter to open AquaProv:

Command Prompt
python main.py

Keep the Command Prompt window open while you use the application. The next time you want to use AquaProv, open Command Prompt, navigate to the same folder, and run python main.py again. You only need to repeat package installation when dependencies change or you use a different Python installation.

macOS: Run from Python Source#

Step 1: Prepare the Folder

Install Python 3.10 or newer using the Python installer for macOS. Extract the complete AquaProv source folder to a location such as your Desktop.

Step 2: Open Terminal

Press Command + Space to open Spotlight, type Terminal, and press Return. Check your Python version:

Terminal · macOS
python3 --version

The version should be 3.10 or newer. Use the Python installation you added in Step 1.

Step 3: Navigate to Your Folder

Use cd to open the directory containing main.py and requirements.txt. For a folder on your Desktop:

Terminal · macOS
cd "$HOME/Desktop/AquaProv"

Replace the example path if you extracted the application somewhere else or the folder has a different name.

Step 4: Install Required Packages

Run the following command and wait for installation to finish:

Terminal · macOS
python3 -m pip install -r requirements.txt

Step 5: Launch AquaProv

Start the application from the same Terminal window:

Terminal · macOS
python3 main.py

For later sessions, navigate to the folder and run python3 main.py again. See the PHREEQC platform note if you want to calculate mineral saturation from chemistry.

Linux: Run from Python Source#

Step 1: Prepare the Folder

Extract the complete AquaProv source folder to your preferred location, such as Downloads. Use a graphical Linux desktop with Python 3.10 or newer and pip available.

Step 2: Open Terminal

Open your system's Terminal application. On many Linux desktops, Ctrl + Alt + T opens it. Check Python and pip:

Terminal · Linux
python3 --version
python3 -m pip --version

If Python or pip is missing, install it using your distribution's instructions. The commands below require a Python installation that permits pip packages. If your distribution manages Python and reports externally-managed-environment, see Troubleshoot Startup.

Step 3: Navigate to Your Folder

Use cd to open the folder containing main.py and requirements.txt. For a folder in Downloads:

Terminal · Linux
cd "$HOME/Downloads/AquaProv"

Replace the example path with the actual folder location on your computer.

Step 4: Install Required Packages

Run the following command and wait until the terminal prompt returns:

Terminal · Linux
python3 -m pip install -r requirements.txt

Step 5: Launch AquaProv

Open the application with:

Terminal · Linux
python3 main.py

Keep the terminal open while AquaProv is running. For later sessions, navigate to the folder and repeat the launch command. See the PHREEQC platform note for calculations from chemistry.

Welcome to AquaProv#

When the application starts, you will see the AquaProv home window. Create a project or open an existing one, then choose an analysis module.

Explore Groundwater, Statistics, Maps, 3D visualization, Assessment, WQI & DWQI, and PHREEQC Mineral SI. Continue with Data Preparation or follow a worked example in the Gallery.

PHREEQC platform note: The source includes an IPhreeqc engine for Windows 64-bit. Calculating mineral saturation from chemistry on macOS or Linux requires a compatible native IPhreeqc library and the AQUAPROV_IPHREEQC_LIBRARY environment variable set to that library's full path before launching AquaProv. Plotting imported SI values does not require this engine.

Open an Existing Project#

Open a saved .aquaprov project from the Home window or press Ctrl + O in the application. If you run AquaProv from Python source, you can also provide the project path when starting it with the commands below.

In Windows Command Prompt, from the source folder:

Command Prompt
python main.py "C:\path\to\study.aquaprov"

On macOS or Linux, use python3 and your actual project path:

Terminal
python3 main.py "/path/to/study.aquaprov"

Troubleshoot Python Startup#

  • Windows cannot find Python: Close and reopen Command Prompt after installing Python. If needed, modify or reinstall Python with the PATH option enabled. If py --version reports Python 3.10 or newer, you can use py -m pip install -r requirements.txt and py main.py instead.
  • Cannot find main.py or requirements.txt: You are in the wrong folder. Open the extracted application folder, copy its full path, and repeat the cd step. The download may contain an extra enclosing folder.
  • No module named pip: On a Python installation from python.org, run python -m ensurepip --upgrade (use python3 on macOS). For a distribution-provided Linux Python, install pip using your distribution's package instructions.
  • A package is missing: Repeat the requirements installation with the same Python command used to launch AquaProv. For Windows, use python -m pip install -r requirements.txt; for macOS or Linux, use python3 -m pip install -r requirements.txt.
  • Externally managed Python: Some Linux distributions and package managers reserve their Python installation for system packages. To follow this direct-install tutorial, use a user-managed Python 3.10 or newer, such as one installed with pyenv, select it for the terminal session, then repeat the version check and installation steps.
  • Using VS Code: Choose Python: Select Interpreter from the Command Palette and select the Python installation where you installed the requirements.
  • The window does not appear: Launch from a terminal and read the error message. If you previously ran headless tests, clear any test settings for QT_QPA_PLATFORM, QT_QPA_FONTDIR and MPLBACKEND, then relaunch on your graphical desktop.

For data, plotting and export problems, see Troubleshooting.

Open the Documentation#

Open docs/index.html in a browser and keep the complete assets/ folder beside the HTML files. The guides, search, filters and bundled downloads work locally. The home page also includes externally hosted media. Read the Privacy Policy for details about external services and data handling.

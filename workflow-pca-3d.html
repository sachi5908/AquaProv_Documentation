Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

The statistical analysis matrixPCA by singular value decompositionThree-dimensional sample scores

The statistical analysis matrix

Let X contain n retained samples (rows) and p explicitly selected measurements (columns). IDs and coordinate columns should only enter if they are the scientific variables being studied. The default rejects missing measurements and constant columns; explicit drop policies use complete rows across the selected variables and record exclusions. There is no automatic imputation, logarithm, outlier removal or conversion from the ion-unit selector.

For standardized analyses, AquaProv subtracts each variable's mean and divides by its sample standard deviation (Jolliffe & Cadima, 2016):

x̄ⱼ = (1/n)∑ᵢ xᵢⱼ
sⱼ = √[∑ᵢ(xᵢⱼ − x̄ⱼ)²/(n − 1)]
zᵢⱼ = (xᵢⱼ − x̄ⱼ)/sⱼ

Center-only PCA/HCA uses xᵢⱼ − x̄ⱼ without division. The standardized sample heatmap and standardized boxplots always use sample z-scores; the scatter matrix displays original units. For the illustrative values 1, 2, 3, the mean is 2, sample SD is 1 and z-scores are −1, 0, 1. Changing the retained rows changes these preprocessing quantities.

Implementation: aquaprovpy/_publication.py (numeric_frame, standardize), aquaprovpy/multivariate.py.

PCA by singular value decomposition

For the centered (optionally standardized) n × p matrix Z, singular value decomposition gives Z = U D Vᵀ. Let dₖ be singular value k and vₖ its variable direction (Jolliffe & Cadima, 2016):

λₖ = dₖ²/(n − 1)
Scores T = Z Vretained
Loadings L = Vretained diag(√λₖ)
Explained variance (%) = 100λₖ / ∑ⱼλⱼ

The retained component count cannot exceed the matrix rank. AquaProv fixes otherwise arbitrary signs by making the largest absolute eigenvector entry positive. Scores locate samples; loadings describe variable relationships with components. Loadings are not the eigenvectors alone. With standardized data, they are correlations between each variable and unrotated PC scores; covariance PCA loadings retain variable-scale effects.

For optional orthogonal Varimax, each loading row is divided by its retained norm (Kaiser normalization), an orthogonal matrix R maximizes the normalized loading simplicity criterion, then row scales are restored (Kaiser, 1958):

Lrot = L R
Trot = T diag(1/√λₖ) R
Rotated variance (%) for k = 100∑ⱼLrot,jk² / ∑ⱼλⱼ

The rotated score coordinates have unit sample variance; their axis percentages come from rotated loadings. Rotation preserves retained communalities and total retained variance, but its axes are not the original ordered PCs. PCA finds variance directions, not causes or proven source contributions. Review preprocessing, retained variance and sample adequacy with the score plot.

Implementation: aquaprovpy/multivariate.py (pca, varimax, plot).

Three-dimensional sample scores

Each point has coordinates (Tᵢ₁, Tᵢ₂, Tᵢ₃), or the first three unit-variance rotated scores. At least three retained components are required. AquaProv uses equal coordinate units across the three axes and reports the sum of their variance percentages. Camera rotation and perspective change the projection on screen, not the calculated coordinates. Apparent proximity from one camera angle can hide separation along the third axis or omitted components.

1. Import this worked input#

Module: 3D visualization. Source: Sukinda_CGWB_Data_2024.xlsx / Selected_47_Samples. Prepared records: 47 (Sahoo et al., 2025).

All 47 source records. All 47 source records; pH, Ca, Mg, Na, K, HCO3, Cl, SO4; sample-SD scaling, three retained components, no rotation or imputation. Orthographic camera with equal PCA coordinate units.

Download this route’s CSV ↓
  1. Open 3D visualization and select PCA · 3D sample scores in the left Plot library. Use its search box to find the plot.
  2. Use Load data in the top toolbar, Ctrl + I, or Data → Dataset → Import CSV or Excel. Import the exact input linked on this page. Select the intended worksheet for a multi-sheet workbook and check the row count and headers in the Data inspector.
  3. Turn Auto update off while entering the worked choices. In the right inspector, open the named tab and click a section heading to expand it; scroll down for the lower controls.
  4. Open Settings → Analysis settings. Check the worked measurement variables, scaling, retained components and rotation. Scores represent samples; loadings represent variables. Use the camera controls to inspect more than one plane.
  5. Click Generate figure or Generate map, or press F5. Open Export → Results & methods to review exclusions, diagnostics, numerical tables and methods before interpreting or exporting the figure.

3. Generate and review the result

Click Generate figure or Generate map, or press F5. Inspect the figure, then open Export → Results & methods for available tables and warnings. Use the final plot preview in the Gallery to review this example.

Interpret the result using the method guide. Inspect numerical outputs under Export → Results & methods. Available result tables include: scores, eigenvectors, loadings, variance, preprocessing, analysis_data, communalities.

4. Refine the figure style

  1. In the right inspector, open Settings → Plot settings. Use Show plot title and Manual plot title (optional); leave the title blank for the automatic title. Set title size, weight, style and position here.
  2. Open Style → Publication figure → Typography. Choose the font family and annotation, axis-label, tick and legend sizes. The top toolbar also provides quick typography controls.
  3. In Style → Publication figure, open Labels & ticks to edit axis labels, visibility, limits, ticks and tick formats. Enter the colourbar title in Color scale label (blank = original). Keep quantity and units in labels; blank labels and limits retain the original labels and automatic bounds.
  4. In the same Publication figure panel, open Canvas & grid to set backgrounds, axis borders, grid visibility and layout padding. For geographic frames, use the map-specific Settings → Coordinates and grid controls when available.
  5. Open Style → Publication figure → Legend & color scale. Set Legend position (also draggable), columns, frame and individual Legend items for this plot. Choose Colour scale, Show colourbar and colourbar text sizes for numeric colours. Sample plots need a numeric colour column for a continuous scale; categorical groups use their group colours. Normalize colour scale to 0–1 changes display labels while retaining measurements and scientific classifications.
  6. Open Style → Publication figure → Dimensions & export. Choose Figure sizing → Custom, then set Width (inches) and Height (inches). Review Transparent background and Crop to content; cropping can change exported dimensions.
  7. Click Apply style and inspect the figure at its intended final size. Save preset and Load preset reuse presentation settings. Method, variable, grouping, sample-symbol and interpolation changes require Generate when Auto update is off.

5. Export and preserve

  1. Finish the calculation with Generate figure or Generate map (or F5). Read the warnings, then apply the final style.
  2. Open Export → Figure export. Enter File name, use Save to → Browse to choose your output folder, then select File format and Image resolution (DPI). Use distinct names for alternative results.
  3. Click the format-specific button, such as Export PNG, Export SVG or Export PDF. Open the saved file and check labels, legends, dimensions and the current view. Raster pixel dimensions depend on figure size and DPI.
  4. Open Export → Results & methods. Select a result table to inspect it. Choose Report format: CSV + JSON, Excel (.xlsx), Word (.docx) or PDF (.pdf), then click its export button. Available tables depend on the plot; some geochemical diagrams do not expose a table for every graphical element.
  5. Press Ctrl + S to save the .aquaprov project, including its data and per-plot settings. Keep the original measurements, exported results and final figure together.

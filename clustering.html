Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

The statistical analysis matrixWard clustering on sample vectors

The statistical analysis matrix

Let X contain n retained samples (rows) and p explicitly selected measurements (columns). IDs and coordinate columns should only enter if they are the scientific variables being studied. The default rejects missing measurements and constant columns; explicit drop policies use complete rows across the selected variables and record exclusions. There is no automatic imputation, logarithm, outlier removal or conversion from the ion-unit selector.

For standardized analyses, AquaProv subtracts each variable's mean and divides by its sample standard deviation (Jolliffe & Cadima, 2016):

x̄ⱼ = (1/n)∑ᵢ xᵢⱼ
sⱼ = √[∑ᵢ(xᵢⱼ − x̄ⱼ)²/(n − 1)]
zᵢⱼ = (xᵢⱼ − x̄ⱼ)/sⱼ

Center-only PCA/HCA uses xᵢⱼ − x̄ⱼ without division. The standardized sample heatmap and standardized boxplots always use sample z-scores; the scatter matrix displays original units. For the illustrative values 1, 2, 3, the mean is 2, sample SD is 1 and z-scores are −1, 0, 1. Changing the retained rows changes these preprocessing quantities.

Implementation: aquaprovpy/_publication.py (numeric_frame, standardize), aquaprovpy/multivariate.py.

Ward clustering on sample vectors

Ward agglomeration begins with one cluster per sample and repeatedly merges the pair with the smallest increase in within-cluster sum of squares. For clusters A and B with means μA, μB and sizes nA, nB (Ward, 1963):

ΔSS(A,B) = [nAnB/(nA+nB)] ‖μA − μB‖²
SciPy Ward merge height = √(2ΔSS)

Distances are Euclidean on the retained observation vectors, standardized if selected. AquaProv does not run Ward on a correlation matrix. The requested cluster count uses an exact merge-count cut; tied heights follow linkage order. Optimal leaf ordering helps readability without changing the merges. Cluster means are exported in the original variable units. Groups depend on variables, scaling and the requested cut and should not automatically be named hydrochemical sources.

Implementation: aquaprovpy/multivariate.py (hca, plot).

Ward hierarchical clustering#

AquaProv clusters samples with SciPy Ward minimum-variance linkage and Euclidean distance on the observation matrix. Sample-SD standardization is the default; center-only analysis is available. A correlation matrix or squared-distance matrix is not the input to this Ward workflow.

Choose the cluster count explicitly. Optimal leaf ordering improves the dendrogram display. When merge heights tie, an exact requested count follows merge order; a unique horizontal cut may not exist. Heights are SciPy linkage distances, not percentage similarity.

Read memberships and means#

Export sample membership, group counts, original-unit means, and preprocessing. Cluster identifiers are nominal names; cluster 3 is not intrinsically more polluted than cluster 1. Review stability and domain evidence before treating groups as distinct water sources. Assessment provides a separate compositional cluster-stability workflow.

Yang: one sampling campaign#

A defensible workflow#

  1. Choose relevant measurements and disclose preprocessing.
  2. Inspect univariate distributions and pairwise plots first.
  3. Generate Ward clustering and review memberships and influential variables.
  4. Assess robustness to measurement selection, scaling, and sampling design; report sensitivity instead of declaring a unique “true” cluster solution.

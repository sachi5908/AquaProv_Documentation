Sample locations

Mathematics and scientific background #

Follow the calculation from inputs to plotted values. The equations and conventions below follow the AquaProv Python implementation. Read them alongside this guide’s worked data, settings and exported results.

What a sample-location map calculates

What a sample-location map calculates

Each retained coordinate pair maps to a marker in the selected display CRS. A background map can reproject the display to Web Mercator; that changes graphical coordinates, not a well's measurement. A displayed attribute can colour a marker, but no value is estimated between markers. A location map has no interpolation equation, prediction variance or groundwater-flow solution. Coordinate metadata, datum, longitude/latitude order and source units determine whether the points are positioned correctly (Snyder, 1987).

Implementation: aquaprovpy/modules/maps/workspace.py, aquaprovpy/locations.py, aquaprovpy/boundaries.py.

Updated geographic export

The 47 original Sukinda sample coordinates within the supplied KML. Measured TDS colours; no interpolated field. True north, 2 km geodesic scale, WGS84 longitude/latitude.

Current numerical tables and methods

The figure and downloadable tables use the geographic coverage and cartography described above.

1. Import this worked input#

Module: Maps & contours. Source: Sukinda_CGWB_Data_2024.xlsx / Selected_47_Samples. Prepared records: 47 (Sahoo et al., 2025).

Measured TDS at the 47 source coordinates, WGS84. Supplied KML polygon shown; all samples fall inside. No basemap or interpolation. True north; a 2 km WGS84 geodesic scale bar at its displayed location; WGS84 longitude/latitude labels on all four frame borders. Cartographic decoration does not change the observations, predictions or masks. The finished map shows true north, a ground-distance scale in kilometres and WGS84 longitude/latitude on all four borders.

Download this route’s CSV ↓
  1. Open Maps & contours and select Sample locations in the left Plot library. Use its search box to find the plot.
  2. Use Load data in the top toolbar, Ctrl + I, or Data → Dataset → Import CSV or Excel. Import the exact input linked on this page. Select the intended worksheet for a multi-sheet workbook and check the row count and headers in the Data inspector.
  3. Turn Auto update off while entering the worked choices. In the right inspector, open the named tab and click a section heading to expand it; scroll down for the lower controls.
  4. Open Data → Sample locations. Select X = longitude / easting, Y = latitude / northing and the declared Source coordinate system. For the prepared geographic examples, choose Longitude, Latitude and WGS84 longitude / latitude (EPSG:4326). Choose Plain coordinates (no background) for an offline background.
  5. When the worked example uses a boundary, open Data → Study-area boundary → Import KML / KMZ / GeoJSON…, select the linked file and check Use study boundary. Otherwise leave it off. For interpolation, match Use only samples inside boundary and Fill entire boundary (extrapolate) to the worked settings; review the support flags in the exported grid.
  6. Open Settings → Map layout for the colour scale controls available for this view. Open Settings → Coordinates and grid for frame coordinates, labelled borders, geographic label format, spacing and line design. Under Settings → North arrow, enable Show north arrow and choose Arrow reference → True north (requires source CRS) for geographic north, or Grid north / +Y for the grid direction.
  7. Open Settings → Scale bar, enable Show scale bar, and choose units, total length, divisions, design and position. When the CRS is unknown, declare the distance unit for local X/Y. Generate and check coverage, labels, north and distance scale together.
  8. In Data → Sample locations, select Measurement / point color and optional Label points by. Under Settings → Contour appearance, set lines, labels, sample visibility, width, basemap overlay and fill opacity for contour views.
  9. Click Generate figure or Generate map, or press F5. Open Export → Results & methods to review exclusions, diagnostics, numerical tables and methods before interpreting or exporting the figure.

3. Generate and review the result

Click Generate figure or Generate map, or press F5. Inspect the figure, then open Export → Results & methods for available tables and warnings. Use the final plot preview in the Gallery to review this example.

Interpret the result using the method guide. Inspect numerical outputs under Export → Results & methods. This legacy diagram does not expose a dedicated numerical result table for every plotted element. Retain the input and settings alongside the image.

4. Refine the figure style

  1. In the right inspector, open Settings → Plot settings. Use Show plot title and Manual plot title (optional); leave the title blank for the automatic title. Set title size, weight, style and position here.
  2. Open Style → Publication figure → Typography. Choose the font family and annotation, axis-label, tick and legend sizes. The top toolbar also provides quick typography controls.
  3. In Style → Publication figure, open Labels & ticks to edit axis labels, visibility, limits, ticks and tick formats. Enter the colourbar title in Color scale label (blank = original). Keep quantity and units in labels; blank labels and limits retain the original labels and automatic bounds.
  4. In the same Publication figure panel, open Canvas & grid to set backgrounds, axis borders, grid visibility and layout padding. For geographic frames, use the map-specific Settings → Coordinates and grid controls when available.
  5. Open Style → Publication figure → Legend & color scale. Set Legend position (also draggable), columns, frame and individual Legend items for this plot. Choose Colour scale, Show colourbar and colourbar text sizes for numeric colours. Sample plots need a numeric colour column for a continuous scale; categorical groups use their group colours. Normalize colour scale to 0–1 changes display labels while retaining measurements and scientific classifications.
  6. Open Style → Publication figure → Dimensions & export. Choose Figure sizing → Custom, then set Width (inches) and Height (inches). Review Transparent background and Crop to content; cropping can change exported dimensions.
  7. Click Apply style and inspect the figure at its intended final size. Save preset and Load preset reuse presentation settings. Method, variable, grouping, sample-symbol and interpolation changes require Generate when Auto update is off.

5. Export and preserve

  1. Finish the calculation with Generate figure or Generate map (or F5). Read the warnings, then apply the final style.
  2. Open Export → Figure export. Enter File name, use Save to → Browse to choose your output folder, then select File format and Image resolution (DPI). Use distinct names for alternative results.
  3. Click the format-specific button, such as Export PNG, Export SVG or Export PDF. Open the saved file and check labels, legends, dimensions and the current view. Raster pixel dimensions depend on figure size and DPI.
  4. Open Export → Results & methods. Select a result table to inspect it. Choose Report format: CSV + JSON, Excel (.xlsx), Word (.docx) or PDF (.pdf), then click its export button. Available tables depend on the plot; some geochemical diagrams do not expose a table for every graphical element.
  5. Press Ctrl + S to save the .aquaprov project, including its data and per-plot settings. Keep the original measurements, exported results and final figure together.
